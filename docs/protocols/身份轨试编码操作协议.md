# 身份轨试编码操作协议

## 1. 任务范围与开始条件

一名作者在一个证据窗口内是一项任务，不按历史帖或片段重复计作者。只使用小红书和条件性知乎已有材料，不自行打开实时主页、搜索新帖、访谈或使用模型建议。主页链接只作追溯。

负责人需提供：适用平台及数值门槛状态、证据窗口与时间规则、来源编号和日期、组件评估状态与角色路径的字段说明。现定小红书5,000、知乎10,000，门槛规则ID为`role-followers-20260924`，状态为THRESHOLD_FROZEN；编码员不自行另选人数线。正式身份任务仍待材料和独立验证完成。

内容编码员不查看身份材料；身份判断不查看T1内容标签或互动结果。后期主页、取整跨界、缺失粉丝不补成可用历史快照。不能用关注数代替粉丝数。

## 2. 专业性、经验分享与持续性

- **EA专业性：** 明确相关专业背景（资格、职业、具体领域认证、机构专业关联）足以使EA=1，无须再证明持续专业分析；没有这些背景，也可由多条历史内容中持续专业分析支持EA=1。保留自述／已有核验来源的区别；一般认证、昵称和单篇详细攻略不自动成立。
- **CE经验分享：** 重复第一手旅行／消费表述与同伴分享取向同时成立；两个日期暂为候选参数，不证明真实消费。低粉KOC路径不要求CE成立。
- **SC：** 旧3日期／30天仅为候选历史覆盖检查，不是背景EA或低粉KOC的共同前提。材料不足不能证明作者不持续创作。

已评估字段用其合法的1／0／UNK／NA；0须有充分覆盖依据。未评估组件留空并单列NOT_ASSESSED，不填成0或UNK。新状态字段仅为文档契约，平台未支持前不能用旧表假装完成。

## 3. 判断角色的顺序

1. 核查单一自然人、旅游UGC纳入、稳定账号和来源时间。机构／多人账号不适用，主体不清保留未知。
2. 在不见粉丝时记录可评估的EA／CE／SC及来源，未评估项明确留存状态，不提前确定角色。粉丝揭示后不得为配合角色改写组件。
3. 核查合格快照与本平台门槛：低粉为小于T_p，达到门槛为大于或等于T_p。小红书4,999为低粉、5,000为达到门槛；知乎9,999为低粉、10,000为达到门槛。不要从五档reach_tier猜小红书是否过门，应核对有效原始数值。
4. 按下表填写候选最终角色及KOC路径；高粉必要组件未完成时最终角色保留UNK，不能据已见粉丝补猜组件。后续补充组件评估须另行安排未见粉丝的独立判断，并保留此前未知记录及新判断来源。
5. 两名编码员独立完成后再讨论必要分歧；原始答案与裁决分别保留，不自动派生或回写金标。

| 条件 | 候选角色 | 必须保留的区别 |
|---|---|---|
| 个人旅游UGC纳入和快照合格且低粉 | KOC_TYPE | SCALE；EA／CE／SC可未测，不能据规模填CE=1 |
| 低粉且另有独立CE=1证据 | KOC_TYPE | BOTH；不是HYBRID，即使EA也为1 |
| 达到门槛、EA=1、CE=0 | KOL_TYPE | 高粉与专业性共同成立，KOC路径NONE |
| 达到门槛、EA=0、CE=1 | KOC_TYPE | EXPERIENCE |
| 达到门槛、EA=1、CE=1 | HYBRID | EXPERIENCE；不能按旧KOL优先规则覆盖 |
| 达到门槛、EA=0、CE=0 | ORDINARY | 其他可判定创作者，不等于普通游客 |
| 高粉必要维度未知，粉丝缺失／取整跨界／时间不合格 | UNK | 不把缺失变成低粉或组件阴性 |
| 机构／多人账号 | NA | 不适用个人角色比较 |

上表低粉路径的“证据充分”按主体与规模等必要条件判断，不要求EA／CE全可测；高粉路径则需要可判断的两轴。人数线已批准；材料、身份验证及平台条件通过前不启动正式任务，不能批量填UNK冒充已开展测量。

## 4. 证据、疑问与教学检查

每个实质判断引用已有来源编号，保存快照实际日期、门槛ID和状态、规则版本、组件评估状态与KOC进入来源。拿不准才标问号并写一句原因，不逐项强制打置信度，不另填分散问题表。未见背景与已核验没有背景不同；不捏造阴性原文。

以下是规则检查用的虚构情形，不是实际编码答案：

- 明确旅游职业、缺少专业分析：EA仍为1；若低粉则KOC，若高粉CE=1则HYBRID，高粉CE未知则角色UNK。
- 无职业资料但持续专业分析充分：EA可为1，不因缺资格直接填0。
- 只有一篇体验但主体与低粉快照合格：可走规模路径KOC；不能将其CE写成1。
- 粉丝恰等于门槛：走达到门槛分支，不能按低粉直接KOC。
- 粉丝原始显示范围跨门槛：角色未知；不把归一化整数当精确观测。
- 高粉但EA、CE都不能判断：不是KOL，也不是其他可判定创作者。

## 5. 负责人验证及分析安排

只读检查现有快照的来源、时间、缺失、取整与同作者多次观测；按已定5,000／10,000人数线分别统计，未有人工组件时只统计规模侧变化，不输出角色人数。材料不够不补采、不放宽门槛凑组，不依据正式内容显著性选择阈值。

先覆盖上述边界和两条KOC来源，记录每名作者实际耗时，再确定校准与新作者盲试安排；不自动恢复25／50名。共同校准不计算正式信度，后续逐组件及最终角色独立验证，检查类别支持、未知和系统性分歧。核心字段alpha至少0.80不等于身份构念已验证。

KOC结果分SCALE、EXPERIENCE及BOTH报告，检查某一路径是否主导差异。粉丝参与定义，控制粉丝或发现组间粉丝差异均不构成独立身份验证；辅助比较需有共同覆盖。身份定义与内容结果有直接重叠的字段只作描述或校验。

人数门槛虽已确定，仍须材料、独立编码、样本支持及平台契约验收后，才能另行恢复正式任务。旧原始答案、角色、快照及规则版本不覆盖、不自动迁移。所有后续问题统一写入[总备忘录](../planning/研究问题与待办总备忘录.md)。
