## 1. 使用什么材料

身份辅助比较目的地形象建构策略。观察单位为“平台账号×选定采集阶段”，同一阶段同一账号只判一次，关联其研究期帖子；不逐篇追溯发帖时身份。规则适用于小红书、知乎、抖音、微博、B站，实际任务仍以负责人发放的材料为准。身份任务覆盖文本样本作者与图片样本发布账号，合并去重后统一判定，结果两轨共用。

**发放顺序：先文本、后身份（2026年10月10日确定）。** 同一组编码员在本批文本及图片任务的首次答案提交并锁定后，才领取身份任务；文本、图片任务中不显示身份资料，已提交的内容答案不因随后看到身份资料而修改。身份材料未齐时不要求文本或图片等待。

**定向边界账号（2026年10月10日确定）：** 试编码另由研究负责人从研究库中定向选取约10个边界账号，与随机关联的账号混合发放，编码员不被告知哪些是定向账号。优先覆盖：低粉或缺粉机构、仅用户名成立的机构、仅认证成立的机构、签约MCN的个人、达到门槛但定位不明的个人、原值恰在门槛两侧的个人、主体模糊或资料冲突的账号，并尽量分布到不同平台。定向账号在记录中单独标记，只用于检验规则是否清楚，不计入身份分布、组别人数或组间比较，也不作为抽样代表性证据。

两人使用负责人统一选定的已有账号资料，包括用户名、认证、简介、主体线索、粉丝原值、来源及实际记录时间或可确认的采集阶段。不补采实时主页，不用目标帖的策略、情感、经历或互动量判身份；内容编码员不查看身份证据。

采用采集阶段身份，资料可以晚于帖子发布时间。负责人统一指定阶段及同一账号多份资料的选用口径；不挑较大粉丝值、不混用阶段、不随今天主页变化更新身份。保留实际时间；只能确认阶段时如实记录，不用帖子日期、导出日期或编码日期冒充资料日期。

## 2. 按这个顺序判断

### 第一步：区分官方／机构与个人账号

先确认旅游内容纳入、账号关联及所用资料来源与阶段。尚未开始的任务保持未测，不批量填UNK。

机构识别用于区分官方发布者与个人创作者。沿用已定证据条件：认证或用户名明确表明账号为机构，任一成立即可；例如虚构名称“海湾市文化和旅游局”“海湾旅行社”。这里包括文旅部门、景区、媒体及企业自身的发布账号，不只指政府账号。无需细究职业标签等级，但脱敏或模糊名称、单独“官方”字样、泛认证标记不能凭猜测补成明确机构证据。

机构直接归**机构账号创作者**`KOL_INST_TYPE`，不设粉丝门槛，也不另判创作者定位；保留支持判断的一项认证或用户名原文、来源和时间。粉丝缺失不影响该判断，缺失不补0；只凭名称认定不写成“已获平台认证”。签约MCN、合作、任职或个人简介中的机构背景，不使个人账号成为机构。主体不清或证据冲突记`UNK`；明确非机构多人共用账号沿用`NA`。

### 机构内部子类辅助设计（尚未启用字段或发放任务）

机构主身份成立后，才进一步使用同一选定采集阶段的已有简介或含义明确的机构用户名区分“官方文旅机构”“旅游企业”“其他机构”“机构类型未明”。这是公开定位的操作分类，不是外部资质核验；不查外网背书、实时主页或实际获利，不用目标帖的宣传、评价和照片倒推身份。

“其他机构”表示已有资料足以确认不属前两类；“机构类型未明”表示不能进一步判断或子类证据冲突。仅知“是机构”不足以判断旅游企业；企业自称“官方”不足以判断官方文旅机构。子类未明不把已成立的主身份改成`UNK`。具体判据以[编码表机构内部子类设计](../data-dictionary/编码表.md#institutional-subtypes-20261021)为准。

当前仍只填已发放的主身份任务，不自行增列、补写旧答案或把子类塞进理由／EA／CE字段。负责人启用子类任务前，须冻结字段和值域版本、材料及保存／导出映射，核验平台后统一发放；是否用于辅助比较先看分平台独立账号数、可判情况与测量质量，不能以帖子数代替账号数，也不自动拆成更多主比较组。

### 第二步：个人账号先看粉丝门槛

粉丝原值直接与本平台门槛比较，等于门槛算达到。保留原值和取整值；已有“万”等显示先按单位换算，不逐个位追查，也不因显示精度或取整跨越旧门槛自动记UNK。粉丝真正缺失或无法读出数值时不能补0。

| 平台 | 个人粉丝门槛（原值比较） |
|---|---:|
| 小红书 | 5,000 |
| 知乎 | 10,000 |
| 抖音 | 2,600 |
| 微博 | 4,600 |
| B站 | 500 |

个人粉丝原值直接与门槛比较：小红书4,999粉低于门槛，5,000粉达到门槛。原始0粉是有效数值，不得写成资料缺失。

低于门槛的个人直接归**普通个人创作者**`KOC_TYPE`，门槛以下个人账号的进入路径记`SCALE`，不补做定位或消费经验判断。

“普通”是本研究的门槛分组简称，可包含简介明确自称旅行博主但低于门槛的个人；不表示已确认游客／居民、非职业、非商业或低实际影响力。达到门槛的个人继续执行下一节的定位核查。负责人已接受这一纳入条件不对称，不追加低粉定位核查；群体比较解释见[编码表](../data-dictionary/编码表.md#creator-comparison-asymmetry-20261021)。

### 第三步：达到门槛的个人再看创作者定位

只看已有简介或含义清楚的认证，判断账号是否明确以旅游及目的地体验相关的内容创作者身份对外活动。

- 明确自称旅行博主、探店博主、签约旅行家等，可作为定位证据；自述与平台认证分别记录，不能按词命中自动分类。
- “想成为博主”“预备役”等准备状态不算；“未签约”等否定表达不算签约证据。单独的合作联系方式、合作意向或无关业务签约也不够。
- 来源性质未核实的职业标签或含义未知的认证代码不能独立定类。
- 不要求专业学历或资质，不恢复EA／CE初判。

定位明确归**达到门槛且定位明确的个人创作者**`KOL_INDIV_TYPE`；定位未见或资料不足记`UNK`，并区分“已核查未见”与“资料不足”。

### 第四步：填写结果

| 条件 | 身份 | 记录 |
|---|---|---|
| 认证或用户名明确支持机构主体，证据可用 | `KOL_INST_TYPE` | 保留机构证据，不看粉丝门槛 |
| 可确认个人，粉丝原值低于门槛 | `KOC_TYPE` | 粉丝原值、取整值、平台门槛及来源；进入路径`SCALE` |
| 可确认个人，粉丝原值达到门槛，且定位明确 | `KOL_INDIV_TYPE` | 粉丝原值、取整值、平台门槛，以及定位证据与来源 |
| 可确认个人，达到门槛但定位未见或资料不足 | `UNK` | 区分“已核查未见”与资料不足 |
| 主体不清、必要主体证据冲突，或个人粉丝缺失／无法读出／阶段不明 | `UNK` | 记录实际缺失或冲突原因 |
| 明确非机构多人共用账号 | `NA` | 单个人路径不适用 |

编码员直接选择细分值，不另写“路径”，也不额外新建人工表格；`KOL_TYPE`不作人工选项，只在分析阶段由`KOL_INST_TYPE`与`KOL_INDIV_TYPE`合并生成。兼具型`HYBRID`保留历史值，本轮不赋值；不新增`ORDINARY`分支。

## 3. 门槛怎样得到

以2026年10月8日工作台研究库的作者级聚合计数为依据：小红书4,014个账号中995个在百位取整后达到5,000，知乎375个账号中34个达到10,000，按作者数加权得到`(995+34)/(4014+375)=23.445%`。保留两平台原数值，另外三个平台采用已查询档位中上层比例最接近该参照的门槛。参照人口包含官方账号；按用户10月9日决定，不先剔除官方重算，不增加纯个人分布复核作为采用前提。门槛一经确定，不随每批样本、平台占比或内容结果自动调整。这是研究内规模分组，不能声称统计上唯一最优或已验证实际影响力。

聚合计数和计算见[探索notebook](../../notebooks/01_follower_thresholds_ugc_20261008.ipynb)。10月8日的候选与解释保留计算历史，10月9日按用户决定采纳上述门槛，10月10日确认保留分平台门槛。这里是分平台人数线，并非对单个账号的粉丝数再乘平台权重。

## 4. 保存与分歧处理

保留作者任务编号、证据窗口、身份、必要证据与来源、实际记录时间、分类规则ID及时间规则ID。个人保留粉丝原值、所用门槛，达到门槛者另留定位证据或未决原因；机构保留足够支持主体判断的名称或认证。全部可识别资料留在受限记录，不进入公开导出。

两名编码员先独立作答，保存原始答案后讨论，裁决另存。平台不支持必要字段时由负责人落实记录载体，不把粉丝、定位或官方识别塞进EA／CE字段。确实拿不准时标疑问并说明。

## 6. 负责人后续处理

试编码覆盖五平台门槛两侧、原值比较、高粉但无简介或定位不明的个人、低粉或缺粉机构、签约个人及主体冲突；随机账号中未出现的情形由上述约10个定向边界账号补足。保存双人答案后讨论，独立验证使用未讨论作者。门槛不为凑组调整，旧记录保留原规则ID，不自动改标或与新规则混用。

身份比较以机构账号创作者、达到门槛且定位明确的个人创作者、普通个人创作者三组分别报告为主，前两组合计只作汇总参考；此口径在查看组间结果前确定。分组不证明真实意见影响力或消费经验。规则确认不等于材料、平台、信度、金标或模型验收；待办统一维护在[总备忘录B02／B06／B15](../planning/研究问题与待办总备忘录.md)。
