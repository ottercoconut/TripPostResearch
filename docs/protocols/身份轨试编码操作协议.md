## 1. 使用什么材料

身份辅助比较目的地形象建构策略。观察单位为“平台账号×选定采集阶段”，同一阶段同一账号只判一次，关联其研究期帖子；不逐篇追溯发帖时身份。规则适用于小红书、知乎、抖音、微博、B站，实际任务仍以负责人发放的材料为准。

两人使用负责人统一选定的已有账号资料，包括用户名、认证、主体线索、粉丝原值、来源及实际记录时间或可确认的采集阶段。简介和职业标签不是个人KOL／KOC的必要条件。不补采实时主页，不用目标帖的策略、情感、经历或互动量判身份；内容编码员不查看身份证据。

采用采集阶段身份，资料可以晚于帖子发布时间。负责人统一指定阶段及同一账号多份资料的选用口径；不挑较大粉丝值、不混用阶段、不随今天主页变化更新身份。保留实际时间；只能确认阶段时如实记录，不用帖子日期、导出日期或编码日期冒充资料日期。

## 2. 按这个顺序判断

### 第一步：区分官方／机构与个人账号

先确认旅游内容纳入、账号关联及所用资料来源与阶段。尚未开始的任务保持未测，不批量填UNK。

机构识别用于区分官方发布者与个人创作者。沿用已定证据条件：认证或用户名明确表明账号为机构，任一成立即可；例如虚构名称“海湾市文化和旅游局”“海湾旅行社”。这里包括文旅部门、景区、媒体及企业自身的发布账号，不只指政府账号。无需细究职业标签等级，但脱敏或模糊名称、单独“官方”字样、泛认证标记不能凭猜测补成明确机构证据。

机构直接归`KOL_TYPE`，不设粉丝门槛；在原有理由栏注明“官方／机构路径”，保留支持判断的一项认证或用户名原文、来源和时间。粉丝缺失不影响该路径，缺失不补0；只凭名称认定不写成“已获平台认证”。签约MCN、合作、任职或个人简介中的机构背景，不使个人账号成为机构。主体不清或证据冲突记`UNK`；明确非机构多人共用账号沿用`NA`。

### 第二步：个人账号只按粉丝门槛分组

粉丝数按百位四舍五入后与本平台门槛比较，达到（含等于）门槛归`KOL_TYPE`，低于门槛归`KOC_TYPE`，不再附加个人创作者定位、简介、职业标签或专业性条件。保留原值和取整值；已有“万”等显示先按单位换算，不逐个位追查，也不因显示精度或取整跨越旧门槛自动记UNK。粉丝真正缺失或无法读出数值时不能补0。

| 平台 | 个人粉丝门槛（百位取整后） |
|---|---:|
| 小红书 | 5,000 |
| 知乎 | 10,000 |
| 抖音 | 2,600 |
| 微博 | 4,600 |
| B站 | 500 |

这里的百位取整为非负人数通常的四舍五入：`100 × floor((原值 + 50) / 100)`。例如小红书4,949→4,900，归KOC型；4,950及4,999→5,000，归KOL型。取整后的0可能来自1—49粉，不得将其写成原始0粉或资料缺失。

个人达到门槛直接归KOL型，即使没有简介、不自称博主或没有职业认证；低于门槛归KOC型，KOC进入路径记`SCALE`。不新增个人定位、消费经验或EA／CE判断，不使用旧高粉定位不明→UNK规则。

### 第三步：填写结果

| 条件 | 身份 | 记录 |
|---|---|---|
| 认证或用户名明确支持机构主体，证据可用 | `KOL_TYPE` | 官方／机构路径；保留机构证据，不看粉丝门槛 |
| 可确认个人，粉丝取整后达到门槛 | `KOL_TYPE` | 个人规模路径；粉丝原值、取整值、平台门槛及来源 |
| 可确认个人，粉丝取整后低于门槛 | `KOC_TYPE` | 个人规模路径，KOC进入路径`SCALE` |
| 主体不清、必要主体证据冲突，或个人粉丝缺失／无法读出／阶段不明 | `UNK` | 仅记录实际缺失或冲突原因，不因没有个人定位而记UNK |
| 明确非机构多人共用账号 | `NA` | 单个人路径不适用 |

兼具型`HYBRID`保留历史值，本轮不赋值；不新增`ORDINARY`分支。官方／机构路径与个人规模路径在原有理由栏分别记录，不额外新建人工表格。

## 3. 门槛怎样得到

以2026年10月8日工作台研究库的作者级聚合计数为依据：小红书4,014个账号中995个在百位取整后达到5,000，知乎375个账号中34个达到10,000，按作者数加权得到`(995+34)/(4014+375)=23.445%`。保留两平台原数值，另外三个平台采用已查询档位中上层比例最接近该参照的门槛。参照人口包含官方账号；按用户10月9日决定，不先剔除官方重算，不增加纯个人分布复核作为采用前提。门槛一经确定，不随每批样本、平台占比或内容结果自动调整。这是研究内规模分组，不能声称统计上唯一最优或已验证实际影响力。

聚合计数和计算见[探索notebook](../../notebooks/01_follower_thresholds_ugc_20261008.ipynb)。10月8日的候选与解释保留计算历史，10月9日按用户决定采纳上述门槛。这里是分平台人数线，并非对单个账号的粉丝数再乘平台权重。

## 4. 保存与分歧处理

保留作者任务编号、证据窗口、所走路径、身份、必要证据与来源、实际记录时间、分类规则ID及时间规则ID。个人保留粉丝原值和取整值、所用门槛；机构保留足够支持主体判断的名称或认证。不再新增个人定位必填字段，旧定位答案留作历史。全部可识别资料留在受限记录，不进入公开导出。

两名编码员先独立作答，保存原始答案后讨论，裁决另存。平台不支持必要字段时由负责人落实记录载体，不把粉丝或官方识别塞进EA／CE字段。高粉且无简介不构成新规则的身份疑问；真实主体或粉丝资料不足仍可标疑问并说明。

## 6. 负责人后续处理

试编码覆盖五平台门槛两侧、百位取整、无简介高粉个人、低粉或缺粉机构及主体冲突。保存双人答案后讨论，独立验证使用未讨论作者。门槛不为凑组调整，旧记录保留原规则ID，不自动改标或与新规则混用。

分组不证明真实意见影响力或消费经验。KOL包含机构与个人时须保留路径区别，不能将全组解释为高粉个人。规则确认不等于材料、平台、信度、金标或模型验收；待办统一维护在[总备忘录B02／B06／B15](../planning/研究问题与待办总备忘录.md)。
