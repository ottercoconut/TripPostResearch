## 1. 使用什么材料

身份用于辅助比较目的地形象建构策略，不单独追求完整的现实身份画像。一项任务对应“平台账号×作者证据窗口”，同一作者窗口的多篇帖子不重复判身份。

只用负责人提供的已有账号资料：主体信息、粉丝原值及实际快照时间、作者简介、含义清楚的创作者认证和来源编号。不自行搜索实时主页、补采帖子或用模型生成答案；不根据目标帖的建议、经历、情感、互动量判身份。内容编码员不查看身份资料。

现阶段使用小红书材料；知乎在材料及平台条件具备时补充。其余平台继续内容编码，本规则不为其新增身份门槛。负责人须提供本批证据窗口、快照适用规则及可保存下列记录的载体；不能把文档更新当作平台功能已完成。

## 2. 按这个顺序判断

### 第一步：确认主体与材料

确认是符合个人旅游UGC纳入条件的单一自然人，账号关联及资料来源明确。机构、商家官方和多人账号记`NA`；主体不清记`UNK`并说明。尚未领取或尚未做的任务保持未测，不批量填`UNK`。

核对粉丝数的来源、精度和时间。缺失不当0，关注数不当粉丝数；取整范围跨门槛或时间不符合本批规则时记`UNK`。不能用后来粉丝数补成发帖时粉丝数。

### 第二步：看是否达到门槛

| 平台 | 低于门槛 | 达到门槛 |
|---|---|---|
| 小红书 | 少于5,000 | 5,000及以上 |
| 知乎 | 少于10,000 | 10,000及以上 |

主体与快照合格且低于门槛，直接记`KOC_TYPE`，进入路径记`SCALE`；不要求再判断创作者定位，也不据此填写“有消费经验”。低粉作者即使自称博主，仍走这条规模路径。

### 第三步：对达到门槛的作者，判断创作者定位

看已有简介或含义清楚的创作者认证，是否明确表示账号以旅游及目的地体验相关的内容创作者身份对外活动。

- 明确自称旅行博主、探店博主、签约旅行家等，可以作为公开定位证据。完整阅读上下文；自述只证明公开定位，不写成已经平台认证。
- “想成为博主”“预备役”等不算；“未签约”不能当签约证据，无关业务的签约也不算。
- 只有合作联系方式、合作意向不够。
- 平台职业标签可以辅助；来源性质未核实的标签、含义未知的认证代码不能单独定类。
- 不要求专业学历或资质，不判断EA／CE／SC；不从目标帖有没有建议、个人经历或情感描写推导身份。

### 第四步：填写结果

| 已核对的情况 | 身份结果 | 记录要求 |
|---|---|---|
| 个人旅游UGC及粉丝快照合格，低于门槛 | `KOC_TYPE` | 规模路径`SCALE`；定位可记未评估 |
| 达到门槛，有明确相关创作者定位 | `KOL_TYPE` | 摘录定位证据，注明自述或认证及来源 |
| 达到门槛，已核查但未见明确定位 | `UNK` | 写“已核查未见”，不自动归KOC或兼具型 |
| 达到门槛，定位资料缺失、语境不清或来源冲突 | `UNK` | 说明资料不足或冲突，不与“已核查未见”混同 |
| 主体不清，或粉丝缺失、取整跨界、时间不合格 | `UNK` | 写明阻止判断的原因 |
| 机构、商家官方或多人账号 | `NA` | 不适用个人创作者分类 |

**兼具型暂不赋值。** 保留`HYBRID`类别及旧记录，但目前没有新的可执行初判标准。不能因为“博主同时分享个人旅行经历”或资料模糊就填兼具型；不使用旧EA／CE矩阵补判。专业背景后置转判也暂不执行。当前不新增`ORDINARY`判断路径，高粉但定位未见按上表处理。

## 3. 保存什么，怎样处理分歧

每项任务记录：作者任务编号和证据窗口、粉丝原值与实际快照时间、平台门槛、定位判断及理由、所用证据摘录与来源、最终身份及未决原因、规则ID。定位判断分为“明确／已核查未见／无法判断／未评估”；不把缺失写成阴性。低粉路径不用为了填满表格补做定位判断。

编码员各自作答，拿不准时标`?`并写一句原因。两份原始答案保存后再讨论，裁决另存，不覆盖原始答案。平台若缺少定位或来源记录位置，先由负责人落实本批记录载体，不能把定位判断塞进旧EA／CE字段。

身份是本研究的操作分组：KOL型表示达到规模门槛且公开以创作者身份活动；KOC规模路径不证明真实消费或同伴取向。两者都不证明实际意见影响力。共同校准不等于独立信度验证。

## 4. 对照示例

以下均为虚构示例，默认主体、账号和快照条件合格：

| 情形 | 填写 |
|---|---|
| 小红书4,999粉，简介“旅行博主” | `KOC_TYPE`，规模路径 |
| 小红书5,000粉，简介明确“旅行博主” | `KOL_TYPE`，保留简介自述证据 |
| 知乎10,000粉，简介仅“商务合作请联系……” | `UNK`，只有合作意向不足 |
| 高粉，简介“想成为旅行博主” | `UNK`，愿望不算明确定位 |
| 高粉，只有来源性质未核实的“旅行博主”标签 | `UNK`，该标签不足以独立判断 |
| 高粉旅行博主，同时发布个人旅行经历 | 符合定位条件则`KOL_TYPE`，不据经历转为兼具型 |
| 景区官方账号，粉丝很多 | `NA` |

## 5. 负责人后续处理

先用现有材料安排小批试编码，记录可判比例、具体分歧及实际用时，再安排未讨论作者的独立验证；不自动恢复旧25／50名配额，不为凑组调门槛。正式研究身份标签、金标和模型仍需材料、独立验证及平台契约验收。
