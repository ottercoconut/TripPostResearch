## 0. 结论先行

1. **项目已经完成“从想法到可执行测量系统”的大部分工作，当前处于 late design／pre-pilot。** 数据冻结、清洗候选、切分1.3.1、编码表v3.21.0、三组身份规则和管理端工作流基本成形；但还没有完成的正式双人试编码、金标、最终人工keep和任何实证结果。
2. **成熟度不均衡，准确说法是“设计成熟、证据尚薄”。** 数据工程与可复现性高；测量设计高；测量效度、抽样比较、实证结果和理论贡献低。不能因为工程做得深，就判断研究已经接近投稿；也不能因为结果章节为空，就否定已有的设计积累。
3. **理论缺口不是“目的地形象论文读得不够”，而是缺少一条把创作者位置、内容策略、资源／属性选择与评价、图文配置连起来的生产端编码链。** 现有文献库强在目的地形象、影响者营销和方法，弱在内容策略、体裁／修辞结构、图文关系和机构角色理论。
4. **建议采用分层理论架构，而不是另立一个大理论。** 最小理论包为“投射形象与形象代理人＋内容／信息策略＋图文关系”；扩展模块为“框架”和“体裁／修辞move”；可选模块为“自我呈现／印象管理”和“制度逻辑／合法性”；平台理论与价值共创只作边界和背景。
5. **最优先补读的8篇**：Tafesse与Wien（2018）、Puto与Wells（1984）、Kislali等（2020）、Kolar与Wattanacharoensil（2020）、Juliaty与Dita（2021）、Martinec与Salway（2005）、Ge与Gretzel（2018）、Du等（2026）。
6. **下一步应并行做两件事**：一是发首批50篇双人试编码（文本＋图片，身份材料另备）；二是用本文件的“理论—字段—输出”表改写论文§2.1、§2.4、§5.2。试编码前不新增编码字段、不改三组规则、不锁定某个新主理论。

### 1.2 研究定位与问题

当前主问题：

> 不同类型的旅游内容创作者，如何运用内容策略呈现青岛的旅游目的地形象？

RQ1问内容策略差异，RQ2问目的地形象内容差异，RQ3问策略与资源、属性、评价如何结合。RQ3是核心，但RQ1／RQ2是必要基础。文本为主轨，身份辅助分组，图片辅助解释；不以帖子内容替代潜在游客实际形成的目的地形象，也不检验受众心理或传播效果。

三组为：

- **机构账号创作者**：认证或用户名明确表明机构主体，不设粉丝门槛；
- **达到门槛且定位明确的个人创作者**：个人粉丝原值达到本平台门槛，且简介或认证明确表明旅游／目的地体验相关创作者定位；
- **普通个人创作者**：个人粉丝原值低于本平台门槛，不另判定位或消费经验。

五平台门槛为小红书5,000、知乎10,000、抖音2,600、微博4,600、B站500。达到门槛但定位未见或资料不足记`UNK`，不自动归入第二组；兼具型本轮不赋值。旧代码`KOL_INST_TYPE`、`KOL_INDIV_TYPE`、`KOC_TYPE`保留兼容，但不代表已验证的KOL／KOC身份。

## 2. 研究成熟度评估

### 2.1 评分口径

采用1—5级，锚点如下：

- **1 未开始**：只有想法或空章节；
- **2 有方案未检验**：文档、规则或工具已写，但没有真实材料反馈；
- **3 小规模试做**：有开发复核、少量试编码或局部验证，但不足以支持正式结论；
- **4 系统证据**：有冻结数据、独立验收、可复现运行或较完整信度证据，但尚未定稿；
- **5 完成可审计**：正式样本、信度、结果、写作与复现材料齐备，可投稿或可交付。

| G5 理论链与贡献 | “身份—策略—资源／属性—评价—图文”的可写解释；与最接近研究的差异 | 未定稿 | B01／B02 |
| G6 分析与写作 | 预分析计划、主要指标、分母、稳健性、结果与讨论 | 未开始 | B13／B15 |

### 2.5 最容易被低估的五个风险

1. **测量复杂度与编码负担。** V3有22个子项、V4有17个二元字段、V6有12个子类；每批50篇完整帖子可能产生数百个片段。若试编码耗时过高，后续批次会被拖慢。需要在首批记录实际用时，而不是只记录一致性。
2. **平台×组别的空格子。** 抖音、知乎样本量小；B站个人门槛低；知乎机构账号极少。严格“先分平台、再合并”的规则下，第4章可能出现大面积“支持不足”。这不是分析失败，但必须在看结果前写清最低作者数与处理方式。
3. **身份材料覆盖不均。** 作者主页URL与简介主要集中在小红书、知乎；B站、抖音、微博的资料不足以按同一规则判断。机构账号总数与分平台数在仓库中没有记录。身份规则“覆盖五平台”不等于五平台都能比较。
4. **图文关系测量缺口。** 当前只有同帖归属和V7／V8四字段，不能直接支持“互补”“冲突”“信息增量”。如果不在试编码中检查字段覆盖，H6很可能只能写成“同帖图文在对象／属性上的对应”，而不是“互补”。
5. **理论段落被留到最后。** 如果等到结果出来再补理论，容易出现“拿结果找理论”或“把描述包装成机制”。理论链应在试编码期间并行写，正式比较前定稿。

## 3. 理论缺口诊断

### 3.1 论文当前的理论状态

论文§2.1已经明确：

> 账号主体与规模／定位分组不自动对应利益相关者角色或形象代理人类型；这些视角尚未作为本文的新解释框架定稿。

§2.4把贡献表述为“一个与现有数据相匹配的、可审计的生产端比较方案”。这一定位是诚实的，但也留下了一个空缺：**为什么不同创作者应该在内容策略、资源调用和属性评价上呈现不同轮廓？** 目前论文能回答“有没有差异”，还不能回答“这些差异在理论上意味着什么”。

具体表现：

- V3的五个父类有操作定义，但没有说明它们来自哪种内容策略理论；
- RQ3以“同片段共现”为基础，但“共现”本身不是理论语言，不能解释为什么某些策略—资源—评价组合会反复出现；
- V0的三组有操作规则，但没有说明“机构／个人、规模／定位”在传播生产中分别代表什么；
- H6只有“同帖对应”，没有图文关系类型学，容易把“同帖出现”误写成“互补”；
- 五平台差异有描述安排，但没有平台理论，容易把平台差异误写成创作者差异。

### 3.2 本地文献库覆盖审计

| 主题 | 本地已有 | 覆盖判断 | 缺口 |
|---|---|---|---|
| 目的地形象概念与形成 | Gartner（1994）、Baloglu与McCleary（1999）、Echtner与Ritchie（1993）、Tasci等（2007）、Gallarza等（2002）、Pike（2002）等 | **强** | 生产端“形象代理人”与“投射／感知”区分的最新讨论不足 |
| 社媒生产端与影响者 | Garay（2019）、Dorta-Preen与Santana-Talavera（2025）、Manthiou等（2024）、Blanco-Moreno等（2024／2026）、Femenia-Serra（2022）等 | **中强** | 创作者类型×内容策略×资源／属性的系统比较少；粉丝分层与身份分组需分开 |

| 平台理论 | 几乎没有 | **弱** | van Dijck与Poell（2013）、Treem与Leonardi（2013）、Liu等（2023） |
| 内容分析／信度方法 | Krippendorff、Mayring、O'Connor与Joffe、Cohen等；近期每日文献还有agreement／validity讨论 | **强** | 方法不是当前主要瓶颈；缺的是把方法用于真实双人编码 |

**判断：** 本地库足以支持“目的地形象是什么、生产端为什么值得研究、怎样做内容分析”；不足以支持“内容策略有哪些理论类型、策略与资源／属性为什么这样组合、图文关系怎样类型化、机构与个人在传播生产上有什么理论差异”。这就是“理论链接不足”的具体位置。

**数量不是主要问题。** 2026-09-07身份轨审查曾清点77个PDF／CAJ文件，其中74个可提取PDF格式、71个不同字节内容；71不是独立论文篇数，因为同一文章可能有不同版本，库里还有论文集、目录材料和统计资料。此后每日文献又新增了若干全文。当前文献库的短板不是“篇数少”，而是**主题结构偏目的地形象与影响者营销，缺少内容策略、体裁、图文关系和机构理论**。继续泛泛下载目的地形象论文，边际收益很低。

### 3.3 一个关键区分：理论层次不同，不能互相替代

- **目的地形象理论**回答“研究对象是什么、不能推断什么”；
- **影响者研究**回答“邻近研究已经做了什么、贡献不能声称什么”；
- **内容策略理论**回答“V3的这些策略在传播学／广告学里对应什么”；
- **体裁／修辞理论**回答“为什么策略、资源、评价会以某种顺序和组合出现”；
- **图文关系理论**回答“文字和图片之间可以有哪些关系”；
- **机构／角色理论**回答“机构与个人在传播生产中的位置差异”；
- **平台理论**回答“为什么平台间不能直接合并”。

把其中任何一个当成“总理论”，都会要么过度解释，要么解释不足。建议按层次组合，而不是寻找一个万能框架。

## 4. 建议的理论架构

### 4.1 总体：生产端编码链

```
创作者位置（V0：机构／达到门槛且定位明确的个人／门槛以下个人）
        │  不是因果，而是“谁在什么位置上生产内容”
        ▼
传播目的与角色期待（机构：公共服务或商业推广；个人：分享／表达；理论解释层）
        │
        ▼
内容策略（V3：信息、知识、情感、互动、其他）
        │
        ├──→ 目的地资源选择（V4：自然／人文／事件／购品）
        ├──→ 被评价或建议的属性（V6：体验／服务／运营／卫生安全）
        └──→ 表达方向与强度（V5：信息／评价／建议；正负与强度）
        │
        ▼
帖子层配置（片段比例、是否出现、策略—资源—属性共现）
        │
        ▼
图文配置（V7—V11＋文本：对象／属性对应、anchorage／relay／elaboration等）
        │
        ▼
三组比较（平台内先报告；满足条件后才合并）
```

这条链是**生产端编码链**，不是“创作者→受众心理→行为”的因果链。它的理论功能是：说明为什么可以把V0、V3、V4、V5、V6、V7—V11放在同一个解释框架里，而不是各自独立地报告频率。

### 4.2 最小理论包（3个核心模块）

#### T1｜投射目的地形象与差异化形象代理人

**核心主张。** 目的地形象的形成涉及多种信息源；社交媒体使生产端出现多类“投射主体”。比较不同创作者，本质上比较的是不同投射位置上的内容选择、组织与评价，而不是比较谁的“影响力”更大。

**关键文献。**
- Gartner（1994）：形象形成过程与信息源类型；本地全文。
- Kislali、Kavaratzis与Saren（2020）：目的地形象形成的整体框架，强调信息源与社会文化因素；摘要级。
- Sun、Tang与Liu（2021）：NTO生成内容与游客生成内容的认知／情感形象差异；摘要级，开放获取。
- Mak（2017）：NTO与游客在线目的地形象比较；题录级。
- Stepchenkova与Zhan（2013）：DMO与用户生成照片的视觉形象比较；题录级。
- Kolar与Wattanacharoensil（2020）：参与式文化下“投射形象”概念的局限；题录级，待全文核读。
- Garay（2019）：社媒帖文的认知／情感属性量化内容分析；本地全文。
- Dorta-Preen与Santana-Talavera（2025）：影响者帖子作为目的地形象数字共创材料；本地全文。

**对应字段／RQ。** V0→形象代理人位置；V4／V6→投射内容；V3／V5→表达方式；V1／V2→披露与平台情境。主要服务RQ2，并为RQ1／RQ3提供上位语言。

**能支持的解释。**
- 三组在资源调用、属性评价和表达方向上呈现不同轮廓；
- 这些轮廓可以解释为不同投射位置的内容差异；
- 研究测量的是生产端内容表征，不是受众实际形象。

**不能支持的解释。**
- 不能把机构等同于Gartner的“induced agent”、个人等同于“organic agent”；
- 不能把机构统称DMO；
- 不能声称某组内容“塑造了”受众形象；
- 不能把组间差异全部归因于身份。

**在本研究中的用法。** 作为RQ2的上位理论语言。操作术语继续用“在线目的地内容表征”；“投射形象”只在文献连接和讨论中使用，并明确“不等于受众形象”。

#### T2｜内容策略／信息策略

**核心主张。** 内容策略可以按“信息性—转换性—互动性”区分：信息性策略提供可核验的事实、参数、路线和知识；转换性策略通过感官、氛围、情感和体验意义组织内容；互动性策略通过提问、号召和社群参与邀请组织内容。三者不是互斥类型，可以组合。

**关键文献。**
- Puto与Wells（1984）：信息性与转换性广告的经典区分；会议论文，题录级。
- Laskey、Day与Crask（1989）：电视广告主要信息策略类型学；摘要级。
- Taylor（1999）：六段信息策略轮；摘要级。
- Ashley与Tuten（2015）：社媒品牌内容的创意策略；摘要级。
- Tafesse与Wien（2018）：信息性、转换性、互动性三类信息策略及其组合；摘要级，开放获取。
- Drossos、Coursaris与Kagiouli（2023）：社媒内容策略综合框架；摘要级，开放获取。
- Fernández Blanco、Ramos Gutiérrez与Hernández-Zelaya（2026）：旅行影响者的内容策略、形式、透明度与互动；摘要级，开放获取。

**对应字段／RQ。** V3五个父类及子项；V5的评价／建议功能作为补充。主要服务RQ1，并为RQ3提供策略侧语言。

**能支持的解释。**
- 三组在信息、知识、情感、互动策略的使用轮廓上存在差异；
- 这些差异可以解释为不同的策略组合，而不是“某组更专业／更真实”；
- 策略组合与资源／属性配置可以进一步比较。

**不能支持的解释。**
- 不能把V3直接称为广告信息策略的原分类；它是本研究的操作分类，需要说明适配；
- 不能推断创作者的主观意图；
- 不能把互动邀请等同于实际互动、准社会关系或传播效果；
- 不能把engagement当作本研究的因变量。

**在本研究中的用法。** RQ1的主要理论语言；RQ3的策略侧。写作时用“策略组合／策略轮廓”，不用“策略导致”。

**V3与信息策略的解释映射（只用于解释，不是新编码规则）：**

| V3父类 | 最接近的理论语言 | 解释 | 注意 |
|---|---|---|---|
| CS-INF 信息提供型 | informational | 提供决策所需的事实、参数、路线、步骤 | 不等于“客观”或“专业” |
| CS-EDU 知识阐释型 | informational（知识／文化信息） | 解释文化、历史、地理、非遗等知识 | 可视为信息性的子型，不另立理论类型 |
| CS-EMO 情感渲染型 | transformational | 通过感官、氛围、主体感受营造体验意义 | 不等于受众情绪感染 |
| CS-INT 互动激发型 | interactional／relational | 提问、号召、社群参与邀请 | 不等于实际互动或准社会关系 |
| CS-OTH 其他／未命中 | residual | 寒暄、结构、元话语、纯符号 | 不强行归入三大策略 |

#### T4｜图文关系与视觉框架

**核心主张。** 文字与图片共同出现时，可以形成不同关系：文字锚定图像意义（anchorage）、图文交替推进叙述（relay）、一方补充另一方未提供的信息（elaboration／extension）、或双方在同一对象／属性上对应。视觉材料还可以在不同层级上被“框架”：外延、风格—符号、内涵、意识形态。

**关键文献。**
- Barthes（1977）：anchorage与relay的经典区分；理论著作。
- Martinec与Salway（2005）：图像—文本的地位关系与逻辑语义关系系统；摘要级。
- Kress与van Leeuwen（2006）：视觉语法；理论著作，本地仅被引用、未确认全文。
- Rodriguez与Dimitrova（2011）：视觉框架的四层模型；摘要级。
- Ge与Gretzel（2018）：中国省级DMO微博帖的视觉策略与图文修辞关系；摘要级。
- Vempala与Preoţiuc-Pietro（2019）：图文关系标注，区分语义重叠与额外信息；摘要级，已在总备忘录核读。

**对应字段／RQ。** V7／V8＋V4／V6＋文本；H6，辅助RQ3。

**能支持的解释。**
- 同帖图文在对象或属性上的“内容对应／图文呼应”；
- 文字可能锚定图像意义，或图像补充文字未提及的细节（前提是已编码）；
- 不同创作者可能采用不同的图文配置（探索性）。

**不能支持的解释。**
- 当前字段不能做“句段—单图”一一对应；
- 不能把同帖共现直接当作“互补”或“信息增量”；
- 不能从图文关系推断受众更相信、更喜欢或更容易被说服；
- 不能把V7／V8四字段当作完整的视觉情感或风格测量。

**在本研究中的用法。** H6的理论语言。先用试编码检查现有字段能支持哪一层关系，再决定是否增设关系任务；不预先增加人工关系标签。

### 4.3 扩展模块（2个）

#### T0｜框架：选择、强调与评价

**核心主张。** 框架是选择某些方面并使其更显著，同时提供评价。媒介／内容框架不同于受众框架；本研究只能研究内容框架。

**关键文献。** Entman（1993）；Scheufele（1999）；Rodriguez与Dimitrova（2011）。

**对应字段。** V4（选择哪些资源）、V6（强调哪些属性）、V5（评价方向）、V3（框架装置）。

**能支持。** 描述内容如何选择、强调和评价目的地面向；比较三组的“框架轮廓”。

**不能支持。** 不能测受众框架；不能称“框架效应”；不新增frame标签。

**用法。** 作为T1与T2之间的中层语言，在§2.1／§5.2用一段说明，不单独设理论章节。

#### T3｜体裁与修辞move

**核心主张。** 旅游帖子是可识别的交际体裁，具有相对稳定的 communicative purposes 和 move 结构。不同创作者可能以不同方式实现这些move，从而形成不同的策略—资源—评价配置。

**关键文献。**
- Swales（1990）：genre作为交际目的与move／step分析；理论著作。
- Bhatia（1993）：专业语境中的体裁分析；理论著作。
- Pascual（2018）：旅行博客帖的修辞结构；摘要级，开放获取。
- Juliaty与Dita（2021）：18篇热门旅行博客帖的四类move：情境（situational）、描述（descriptive）、收束（closure）、邀请（invitational）；摘要级，开放获取。
- Bosangit、Hibbert与McCabe（2015）：旅行博客中的自我反思、情感与意义；摘要级，开放获取。
- Anesa（2018）：旅行博客的体裁混合性；摘要级，开放获取。

**对应字段。** 片段序列＋V3／V4／V5／V6；主要服务RQ3。

**能支持的解释。**
- RQ3的共现可以解释为“move-specific配置”，而不是任意标签组合；
- 某些策略—资源—评价组合反复出现，可能对应旅行帖的典型交际任务；
- 三组可能在move repertoire或move实现方式上不同。

**不能支持的解释。**
- 当前编码表没有move标签；语义片段不等于move；
- 四类move来自一项18篇博客的研究，不是普遍框架；
- 不能在未标注move的情况下声称“某组缺少某move”。

**用法。** RQ3的解释语言；可选在首批试编码后做小规模post-hoc move标注，检验语义片段与move是否对齐。该标注不进入正式编码表，除非另行验证。

### 4.4 可选模块（2个）

#### T5｜自我呈现与印象管理

**核心主张。** 自我呈现区分“印象动机”与“印象建构”；旅游自拍可以理解为对象化的自我呈现。机构与个人在正面表达、人物呈现和消费符号上可能存在不同倾向，但动机不可由内容直接推断。

**关键文献。** Goffman（1959）；Leary与Kowalski（1990）；Lyu（2016）。

**对应字段。** V9人物呈现、V10消费符号、V3情感、V5正面／负面。

**能支持。** 把机构／个人的正面表达与人物呈现差异解释为“与自我呈现线索一致”。

**不能支持。** 不能测动机；不能假定机构一定正面；不能把差异归因于印象管理。

**用法。** §5.2讨论的辅助语言；未来研究可访谈或实验。

#### T6｜制度逻辑与合法性

**核心主张。** 官方文旅机构、旅游企业和其他机构的合法性基础与注意力分配可能不同：公共机构更强调公共使命与规范合法性，企业更强调市场逻辑。这可能影响内容策略与资源选择。

**关键文献。** Suchman（1995）；Thornton与Ocasio（1999）；Pike与Page（2014）。

**对应字段。** V0机构子类（未启用）＋V3／V4／V6。

**能支持。** 如果子类启用，提出“官方文旅机构 vs 旅游企业”的解释性预期。

**不能支持。** 当前子类字段未启用；只有公开定位，没有组织目标或实际经营数据；不能把机构统称DMO。

**用法。** 暂不作为主理论；等B06核验子类账号数与资料可判情况后再决定是否启用。

### 4.5 边界模块（2个）

#### T7｜平台可供性与社交媒体逻辑

**核心主张。** 平台的可见性、可编辑性、持久性、关联性，以及可编程性、流行度、连接性和数据化，塑造内容格式、可见性与互动方式。平台差异不能直接归因于创作者。

**关键文献。** van Dijck与Poell（2013）；Treem与Leonardi（2013）；Liu、Wang与Zhang（2023）。

**对应字段。** V2平台／媒介；平台分层报告。

**能支持。** 解释为什么平台间内容不同、为什么不能直接合并；为“平台内先报告”提供理由。

**不能支持。** 没有算法、推荐或平台政策数据；不能把平台差异归因于创作者；不能声称平台导致某种内容。

**用法。** §3方法与§5局限的边界语言；不做独立理论章节。

#### T8｜价值共创

**核心主张。** 目的地形象由多主体共同生产；UGC是共创行为的痕迹，但不等于受众端的价值生成。

**关键文献。** Vargo与Lusch（2004）；Dorta-Preen与Santana-Talavera（2025）；Zhao与Agyeiwaah（2024）；Iglesias-Sánchez等（2020）。

**对应字段。** V0／V4／V6；没有互动过程或受众价值数据。

**能支持。** 作为宏观背景：目的地形象是多主体共同生产的，不是DMO单方面投射。

**不能支持。** 不能测共创过程或价值；不能把UGC等同于共创；不能推断受众价值或满意度。

**用法。** §2.1背景一段；不作为核心机制。现有[价值共创理论梳理](../../literature/价值共创理论梳理_2026-09-30.md)已经明确“内容型数据可观测度高，但不能推断受众价值”，沿用该边界。

### 5.1 从RQ到理论语言的写法

| RQ | 当前测量 | 现在的解释缺口 | 建议的理论语言 | 结果呈现 |
|---|---|---|---|---|
| RQ1 | V3策略轮廓 | 为什么三组策略不同 | 信息／转换／互动策略组合 | “策略组合／策略轮廓”，不写“策略导致” |
| RQ2 | V4资源、V6属性、V5方向与强度 | 为什么资源／属性显著性不同 | 投射形象与形象代理人；内容框架 | “投射内容／资源与属性轮廓”，不写“受众形象” |
| RQ3 | 同片段共现＋帖子汇总 | 为什么某些组合反复出现 | 体裁／move；策略—资源配置 | “编码配置／move-specific组合”，不写“机制” |
| H6 | 同帖图文＋V7／V8 | 图文之间是什么关系 | 图文关系类型学；视觉框架 | “内容对应／图文呼应”，不写“互补效应” |

### 5.2 图文关系的最小词汇

| 关系 | 最小定义 | 现有字段能否直接支持 | 可以说 | 不能说 |
|---|---|---|---|---|
| 同帖归属 | 文字与图片属于同一帖子 | 可以 | 材料可以关联 | 句段与单图一一对应 |
| 对象／属性对应 | 图文涉及同一对象或同一属性 | 部分可以（V4／V6与V7对照） | 内容对应／图文呼应 | 互补、信息增量、因果 |
| Anchorage | 文字固定或解释图像意义 | 当前无关系标签 | 文字可能锚定图像意义 | 已测anchorage |
| Relay | 图文交替推进叙述 | 当前无关系标签 | 可作为未来编码方向 | 已测relay |
| Elaboration／extension | 一方补充另一方未提供的信息 | 当前无关系标签 | 可作为未来编码方向 | 已测互补 |
| Contradiction | 同一对象／属性上图文评价相反 | 当前无关系标签 | 可检查反例 | 已测冲突 |

**结论：** 现有字段最多支持“同帖归属＋对象／属性对应”。在试编码中应先检查这一点，再决定是否增加关系任务。不要因为负责人说“出现共现就可以”就把“共现”升级为“互补”。这句话应保留在总备忘录B13的记录里，作为讨论起点，而不是测量规则。

### 6.4 从案例中能学到的五件事

1. **分组必须独立于内容。** 高淑情等（2026）按“谁制作”分OGC／TGC；何文俊与吴恒（2026）按居民／DMO分；Li与Peng（2026）按本地／非本地分。共同点是分组依据来自账号或制作主体，不用目标帖的策略反推身份。这与本项目B02的要求一致。
2. **结构指标比单纯频次更有解释力。** 何文俊与吴恒用典型度、本真度等结构指标；Zuo等（2023）用共现分析；Zhan等（2023）用QCA组态。它们都在回答“要素如何组合”，而不只是“出现了多少次”。这支持RQ3从“频次”走向“配置”。
3. **样本边界要写清。** Li与Peng只含高互动视频，明确不能预测普通视频走红；Blanco-Moreno等（2025）是单平台、观察性数据；Tham等（2024）是小样本质性。写作时应把“样本是候选人口还是最终研究人口”写清，不能用高互动样本代表总体。
4. **图文关系需要独立标注。** Ge与Gretzel（2018）用修辞结构理论分析图文关系；Tan等（2025）做单元级多模态；Zhao与Agyeiwaah（2024）把照片与文本一起分析。它们都说明“分别统计文本和图片”不足以回答图文关系。本项目若要支持H6，需要先检查现有字段能否支持对象／属性对应。
5. **不要把互动量当内容效果。** Blanco-Moreno等（2025）、Guo等（2024）、Fernández Blanco等（2026）都把互动作为结果变量；本项目明确不采集受众端结果，因此只能借用其自变量侧的编码与分组，不借用其效果结论。Yasar等（2026）用评论推断观众解读，是一个应避免的反例。

## 8. 对论文写作的直接建议

### 8.1 §2文献综述的重排

建议把当前§2从“概念边界＋相邻研究＋受众机制＋研究空白＋方法文献”改为六段：

1. **§2.1 目的地形象与生产端内容表征。** 保留Gartner、Tasci、Echtner与Ritchie；加入Kislali等（2020）、Kolar与Wattanacharoensil（2020）、Sun等（2021）；明确“投射形象≠受众形象”，但“投射形象”可以作为上位文献语言。
2. **§2.2 内容策略与信息策略。** 加入Puto与Wells（1984）、Tafesse与Wien（2018）、Drossos等（2023）、Ashley与Tuten（2015）；说明V3五类是本研究的操作分类，不是直接照搬。
3. **§2.3 目的地资源、属性与评价。** 保留V4／V6的旅游标准与目的地形象属性文献；加入“选择—强调—组织—排除”的表述（Du等，2026）和框架理论（Entman，1993；Scheufele，1999）。
4. **§2.4 图文关系与多模态。** 加入Barthes（1977）、Martinec与Salway（2005）、Ge与Gretzel（2018）、Rodriguez与Dimitrova（2011）；明确当前只做“内容对应”，不声称“互补”。
5. **§2.5 创作者位置、平台与比较边界。** 保留身份分组的操作说明；加入平台可供性（van Dijck与Poell，2013；Treem与Leonardi，2013）；说明为什么平台内先报告。
6. **§2.6 研究空白与贡献。** 不再写“首次”“空白”；写“生产端编码配置”的经验贡献、片段级多模态编码的方法贡献、中国多平台语境的材料贡献。贡献表述与最接近研究逐项对照，不用“创新点”列表代替。

### 8.2 §5讨论的解释语言

| 可以写 | 不要写 |
|---|---|
| 三组呈现不同的内容策略组合 | 某组更专业／更真实／更有影响力 |
| 三组在资源与属性上呈现不同的投射轮廓 | 某组“塑造了”受众的目的地形象 |
| 某些策略—资源—评价组合反复出现，可解释为move-specific配置 | 共现证明了意义迁移或因果传导 |
| 同帖图文在对象／属性上存在内容对应 | 图文互补产生了更强传播效果 |
| 机构与个人的差异与自我呈现线索一致 | 机构一定正面，或个人一定真实 |
| 平台间差异需要平台内解释 | 平台差异全部由创作者类型造成 |
| 研究测量的是生产端内容表征 | 研究测量了受众认知、情感或意动形象 |

### 8.3 贡献表述的三个层次

1. **概念层**：把“不同类型创作者的目的地内容”明确为生产端编码链，区分“投射内容”与“受众形象”，并说明身份分组只支持生产端比较。
2. **经验层**：如果结果支持，说明三组在“策略组合—资源选择—属性评价”的配置上是否存在差异；差异是“关注对象不同”还是“对相同对象的评价不同”。不要预先承诺一定有差异。
3. **方法层**：片段级语义切分＋双人编码＋多标签信度＋模型扩展；图文同帖关联但不强加句段—单图对应。方法贡献要等信度和模型结果支持后再写。

最稳妥的贡献表述是**中层贡献**：不是提出一个新理论，而是把“创作者位置—内容策略—资源／属性评价—图文配置”做成可审计的生产端编码框架，并在中国多平台材料上检验其可行性。这个表述既保留了理论野心，又不需要受众数据或因果识别。

### 8.4 三个解释性命题（非方向性，不作为新假设）

- **P1（策略组合）**：三组的内容策略组合可能不同，因为其传播位置、受众期待和责任约束不同；差异可能表现为信息／转换／互动策略的相对比重，而不是某一策略的有无。
- **P2（资源与属性配置）**：策略组合差异可能伴随资源选择与属性评价的差异；需要区分“关注不同资源／属性”与“对相同资源／属性作不同评价”。
- **P3（图文配置，探索性）**：三组可能在图文关系上不同，差异可能表现为文字与图像在对象／属性对应、意义锚定或信息补充上的不同组合；但当前字段不足以直接检验，只能作为探索性阅读，不写成方向性假设，也不据此预填任何关系标签。

这三条只用于讨论和写作组织，不进入H1—H8，不改变现有假设的非方向性。

### 8.5 与现有RQ／H的关系

- H1—H5继续是非方向性比较；理论模块只提供解释语言，不改变假设方向。
- H6保持条件启动；先用试编码检查V7／V8能否支持“内容对应”，再决定是否写“互补”。
- H7在试编码反馈后讨论；不要用理论预期代替披露状态的实际记录。
- H8保持`DEFERRED`；平台理论只说明为什么不能直接合并，不构成平台异质性的检验。
