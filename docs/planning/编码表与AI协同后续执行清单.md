## 一、研究主线

当前论文保留原研究问题和假设层级：

1. RQ1保留目的地资源、内容呈现、语言功能、表达方向与评价属性的分布和组合特征；
2. RQ2与H1—H2保留KOL型/KOC型的IMP与CSP轮廓比较；
3. RQ3保留评价性内容表征以及触达规模/平台稳健性；H5保留互动信号轮廓比较；
4. RQ4与H3、H4、H6—H8保留共现、属性—情感关联、图文对应、披露及异质性候选分析，但仍受各自质量门和`DEFERRED`状态约束。

当前不研究的仍是受众态度或行为效果、创作者真实意图和因果传播机制。H1—H8及IMP、CSP、ATP、ATD、AIP、SRM、SAM、COD、IFD、CED、CEI、CER均保留；“保留”不等于已启动，须按各自的数据门和质量门执行。

## 二、人工与程序的顺序

唯一顺序为：

`规则共同校准 → 新样本盲试标 → 完全人工正式编码 → 人工裁决与金标锁定 → 模型训练和锁定测试 → 程序扩展非金标样本 → 正式分析`

人工金标阶段：

- 不显示模型建议；
- 不运行自动标签派生；
- 不用程序补值、纠错或覆盖人工答案；
- 两名编码员的原始记录与裁决记录分开保存。

金标锁定后，程序可以转换训练格式、计算汇总、训练模型和处理非金标样本，但不能回写人工金标。当前三周校准和首轮正式金标不启用模型低置信度回流；原主动学习候选若以后启动，须放在最终模型锁定前另立预注册实验轮次，模型只选样、不向编码员建议标签。最终训练完成并进入非金标生产编码后，人工完全退出。

## 七、阶段3：模型训练与锁定测试

### 最小可执行模型路径

1. 建立一个可复现的基础模型；
2. 在开发集设定阈值；
3. 只在最终模型冻结后使用锁定测试集；
4. 对每个标签报告Precision、Recall和F1；
5. 同时报告macro-F1与micro-F1；
6. 只将达到预定性能的标签用于大样本主分析。

### 保留的后续候选实验

- 主动学习与等预算实验；
- 文本或图片数据增强；
- 复杂层级损失；
- Brier score和全套概率校准；
- 每个平台与每种角色的完整子群模型评估；
- 最终模型锁定前、另行预注册的模型不确定样本选样实验。

这些项目是原AI协同研究设计的保留部分。本轮不决定删除、启动或修改它们；正式执行时仍需学习曲线、同预算对照、消融和锁定测试证据。

### 模型通过条件

- [ ] 训练、开发、测试没有作者或重复簇泄漏。
- [ ] 每标签Precision、Recall、F1完整报告。
- [ ] 主要标签达到预先写明的最低标准。
- [ ] 低频或低性能标签被标为探索性或不进入主分析。
- [ ] 人工金标结果与模型预测结果分开保存和报告。

## 九、阶段5：帖子与作者聚合

每个片段的同一标签只有0或1；同一标签可在不同片段重复。裁决后计算：

| 层级 | 指标 | 用途 |
|---|---|---|
| 帖子 | 标签出现次数 | 描述一帖出现几次 |
| 帖子 | 出现次数÷有效片段数 | 主要组间比较，控制长帖机会更多 |
| 帖子 | 是否至少出现一次 | 补充敏感性结果 |
| 作者 | 各帖子标签比例的平均值 | KOL型/KOC型主比较，使作者等权 |

- [ ] 明确空帖、无有效片段和结构性NA的处理。
- [ ] 抽查聚合结果可追溯到片段金标或模型输出。
- [ ] 按编码表保留IMP、CSP、ATP、ATD、AIP、ISP与各项`DEFERRED`候选指标；它们只在对应质量门通过后计算，且不进入人工编码界面。

## 十、阶段6：统计分析（保留原设计）

> 本节只登记与编码产出的衔接点，不在本轮收缩研究问题、假设、指标或统计模型。最终方法将在正式抽样框和标签支持量可见后单独预分析。

### RQ1

- [ ] 报告标签频数、帖子比例、是否出现和95%置信区间。
- [ ] 分开呈现人工金标与模型扩展样本。

### RQ2

- [ ] 主组只包含证据充分并经裁决的KOL型与KOC型。
- [ ] HYBRID、ORDINARY、UNK与NA单列。
- [ ] 分类结果使用卡方或Fisher检验并报告Cramér's V。
- [ ] 作者级比例根据分布使用Welch t检验或Mann–Whitney U检验，并报告相应效应量与区间。
- [ ] 在对应质量门通过后，分别构建IMP、CSP与ISP以评估H1、H2与H5。

### RQ3

- [ ] 报告KOL型/KOC型的触达规模和平台分布。
- [ ] 以分层结果或简单回归检查差异方向。
- [ ] 样本不足时只做描述，不强行建立复杂模型。

### RQ4

- [ ] 仅在视觉人口、V7标签和V4—V7映射通过后启动。
- [ ] 以帖子为配对单位计算至少一个资源是否匹配。
- [ ] 多图帖、无图和不可判图片按冻结规则处理。

### 候选假设

- [ ] H3的SRM仅在分母支持、原子标签质量与模型下游效度通过后启动。
- [ ] H4的SAM/AAM仅在对应V4—V6字段与同`seg_id`配对质量通过后启动。
- [ ] H6—H8分别等待图文映射、披露样本支持及平台/触达规模支持。

### 通用统计规则

- [ ] 分析前写明主要指标和检验，不根据显著性更换方法。
- [ ] 检查分布、极端值和缺失。
- [ ] 每项检验报告效应量，不只报告p值。
- [ ] 同一指标族使用FDR控制多重比较。
- [ ] 不把非显著结果写成“完全没有差异”。
- [ ] 不把观察性组间差异写成因果效果。
