## 一、目的与边界

本文回答一个问题：**在不新增人工字段的前提下，现有V4（文字）与V7（图片）编码能支持什么样的图文内容对应指标。**

- 采用10月21日确认的表述“内容对应／图文呼应”：同一帖子的文字与图片涉及同一**内容域**。
- 单位是帖子。文字取全部固定片段的出现性汇总，图片取本帖全部已编码图片；**不建立片段—单图对应**。
- 不合成单一“图文一致性得分”：内容对应、单向未对应、视觉呈现格式分别报告。
- 测不到的内容见第六节，不由本文指标替代。

## 二、映射表

### 2.1 主映射（严格，三个内容域）

| 内容域 | 文字侧：帖子内任一片段为1 | 图片侧：`visual_subject` | 说明 |
|---|---|---|---|
| D-NAT 自然景观 | `rs_n_geo`、`rs_n_wat`、`rs_n_bio`、`rs_n_cli` | `VS-NAT` | 文字四类合并；图片分不出海、山、植物、天象 |
| D-BLT 建成环境 | `rs_r_his`、`rs_r_arc` | `VS-ARC`、`VS-FAC` | `rs_r_arc`同时含建筑外观与住宿／交通／服务设施，图片侧分属ARC与FAC，只能合并成一域 |
| D-FOD 饮食 | `rs_r_gas` | `VS-FOD` | 菜品、饮品为主体 |

主映射中的**可映射图片**为`VS-NAT`、`VS-ARC`、`VS-FAC`、`VS-FOD`四类；每张图只属于一个域。

### 2.2 宽松映射（敏感性分析用）

| 追加对应 | 理由 | 风险 |
|---|---|---|
| `VS-FAC` ↔ `rs_r_gas`（同时计入D-FOD） | 图片判据把餐厅空间、柜台、就餐设施归`VS-FAC`；文字写就餐体验多记`rs_r_gas`。负责人举的“文字写就餐环境、图片拍环境”只有在这条映射下才算对应 | 酒店大堂等非餐饮设施图也会被算进饮食域，抬高D-FOD对应 |
| `rs_r_gds` ↔ `VS-FOD`（计入D-FOD） | 作为特产介绍的食品类购品在图片上记`VS-FOD` | 编码无法区分食品与非食品购品；冰箱贴类会被误计 |
| D-ACT 人的活动与生活：`rs_r_rec`、`rs_r_evt`、`rs_r_fol`、`rs_r_lif` ↔ `VS-PEO` | 活动、节事、民俗、日常生活在图片上常以人物为主体 | `VS-PEO`也包括与资源无关的自拍和打卡照，V9未启用，无法区分；只作探索 |

宽松映射下一张图可同时属于两个域（`VS-FAC`属于D-BLT与D-FOD），第三节的定义已按此处理。

### 2.3 不进入映射、单独报告

| 项目 | 处理 |
|---|---|
| `VS-OTH`（地图、文字截图、票据、无主次拼图等） | 不属于任何域；按组报告其占全部图片的比例 |
| `VS-PEO`（主映射下） | 不属于任何域；按组报告其比例，作为“人物主导”的呈现格式描述 |
| 文字侧`rs_r_rec`、`rs_r_evt`、`rs_r_fol`、`rs_r_lif`、`rs_r_gds`（主映射下） | 图片侧无对应类别；可报告其出现率，但不计算图文对应 |
| V8 `SC-ICO`标志性场景 | 文字侧现可用程序变量`mentions_2026_landmark_list`描述“正文提及2026清单地点”，但它不表示图片实际所拍地点，也不是V8人工标签；仍不用于对应 |

## 三、帖子层变量

记号：帖子 *p* 的固定片段集合 *S(p)*，已编码图片集合 *M(p)*，内容域 *d*。

| 变量 | 定义 |
|---|---|
| `T_d(p)` | 文字提及：*S(p)*中任一片段的*d*域文字字段为1则为1；全部片段该域字段均为0则为0；否则（无1且存在`UNRESOLVED`）为NA，*p*不进入*d*域指标 |
| `dom(m)` | 图片 *m* 按所选映射所属的内容域集合；`VS-OTH`、主映射下的`VS-PEO`为空集 |
| `n_img(p)` | 本帖已编码图片数，不含V7为`UNRESOLVED`的图片 |
| `n_map(p)` | 本帖可映射图片数，即`dom(m)`非空的图片数 |
| `s_d(p)` | *d*域图片占比 = *d*∈`dom(m)`的图片数 ÷ `n_map(p)`；`n_map(p)=0`时为NA |
| `J_d(p)` | 图片呈现：至少一张图片的`dom(m)`含*d*则为1，否则为0 |

## 四、指标

### 4.1 主指标：对应差（每个内容域分别计算）

```text
Δ_d = E[ s_d | T_d = 1 ] − E[ s_d | T_d = 0 ]
```

含义：文字提及*d*的帖子，比不提及*d*的帖子，*d*类图片占比高多少个百分点。

- **为什么用条件差而不用重叠率。** 在青岛，写海的帖子几乎都会配海景，“任一重叠”会接近100%。Δ用不提及该域的帖子作为基准：图片与文字无关时Δ约为0，正值才表示图片随文字内容而变。
- **为什么用占比而不用“是否出现”。** 图片越多，某类图片至少出现一张的概率越高；占比对图片数量不那么敏感。二元版本作为敏感性分析（4.3）。
- **为什么按域条件化。** 比较对象限于提及或不提及同一域的帖子，因此某组多写美食，不会机械地抬高该组的D-FOD对应差；题材差异另由RQ2的V4轮廓报告。

### 4.2 描述指标

| 指标 | 定义 | 用途 |
|---|---|---|
| 文到图呈现率 `R_d` | P(`J_d`=1 ∣ `T_d`=1) | 文字提及*d*的帖子中，图片也呈现*d*的比例 |
| 图到文提及率 `Q_d` | P(`T_d`=1 ∣ `J_d`=1) | 图片呈现*d*的帖子中，文字也提及*d*的比例 |
| 文有图无 `A(p)` | Σ_d `T_d(p)`·(1 − `J_d(p)`) | 文字提及、但没有任何对应图片的内容域个数 |
| 图有文无 `B(p)` | 可映射图片中，`dom(m)`与本帖`T_d=1`的域没有交集的图片所占比例 | “图片呈现了文字未提及的内容”在类别层的近似 |
| 呈现格式 | `VS-OTH`、`VS-PEO`各占`n_img`的比例 | 拼图、截图、人物主导等格式的组间差异 |

`R_d`、`Q_d`、`A`、`B`都受该域本身出现率的影响，不单独解释为对应强弱。`A`与`B`须对照置换基准（4.4）。

### 4.3 敏感性分析（与主指标一并预先确定）

| 编号 | 改动 | 检查什么 |
|---|---|---|
| S1 | 宽松映射代替主映射 | 餐饮空间、食品购品、人物活动是否改变结论 |
| S2 | 二元版：`Δ^J_d` = P(`J_d`=1 ∣ `T_d`=1) − P(`J_d`=1 ∣ `T_d`=0) | 结论是否依赖“占比”这一选择 |
| S3 | 按图片数分层（1张、2—4张、5—9张、10张及以上）分别计算Δ | 图片数量的组间差异是否驱动结果 |
| S4 | 只用首图（显示顺序第一张）代替全部图片 | 封面与正文配图是否表现不同；需先核实平台`img_id`即显示顺序 |
| S5 | 排除`VS-OTH`占比 ≥ 0.5 的帖子 | 拼图、截图密集的帖子是否主导组间差异 |

### 4.4 置换基准（用于`A`、`B`等描述指标）

在同一平台、同一图片数分层内，固定文字编码不变，把各帖的整组图片编码随机互换，重新计算指标；重复1,000次，报告“观测值 − 置换均值”及置换分布的2.5%—97.5%区间。差值接近0表示该描述量与图文无关的随机配对没有区别。

## 五、组间比较（H6）

**作者等权。** 旧切片中多数作者只有一帖，对应差不能在作者内部计算，故按条件格作者等权：

```text
E_g[ s_d | T_d = c ] = 组g内、至少有一篇满足 T_d = c 的作者，各自在这些帖子上的 s_d 均值，再对作者取平均
Δ_d,g = E_g[ s_d | T_d = 1 ] − E_g[ s_d | T_d = 0 ]
```

一名作者可以同时进入c=1和c=0两个格。

**比较与不确定性。** 报告各组的Δ_d,g及组间差Δ_d,g1 − Δ_d,g2；在组内按作者重抽样（2,000次）求区间，组别差异用作者层面的组标签置换检验。每个平台先分别报告，合并时按平台分层。

**格子支持。** Δ_d,g需要c=1与c=0两个格都有足够作者。每格最低作者数应与R6一并在看结果前确定，本文不替其决定；未达标时只报告描述量。

## 六、纳入条件与状态处理

| 情形 | 处理 |
|---|---|
| 媒介形态 | 主分析只用`media_type = IMAGE_TEXT`。`VIDEO_TEXT`待视频封面／抽帧口径（编码表§0视觉T0门）确定后另行报告；`TEXT_ONLY`、`LIVE`不进入，只报告数量 |
| 编码顺序 | **前提**：同一帖子的图片在编码员阅读正文前完成并锁定。顺序未满足时，图片判断可能受文字引导，Δ会被高估；实际顺序须记录在任务元数据中 |
| 版本 | 同一帖子的文字与图片答案须注明各自`codebook_version`。`rs_r_gds`（v3.21.0起）、`rs_r_lif`（v3.24.3起）、`VS-OTH`（v3.24.1起）缺列时记NA，不补0；涉及这些字段的宽松映射只用具备相应版本的帖子 |
| 疑问标记`?` | 按已填值计入，另报告各指标中带`?`的记录数 |
| 图片`UNRESOLVED` | 不计入`n_img`与`n_map`，报告数量 |
| `n_map(p)=0` | 不进入占比类指标（Δ、`B`），仍进入`J_d`、`A`和呈现格式 |

## 七、能说与不能说

| 指标支持的陈述 | 指标不支持的陈述 |
|---|---|
| 在某内容域，图片呈现随文字提及而变化的程度（类别层的内容对应） | 图文指向**同一对象**（如文字写栈桥、图片拍八大关也算建成环境对应） |
| 各组在类别层“文有图无”“图有文无”的差异，相对随机配对的大小 | 图片提供了多少**额外信息**；类别层的“图有文无”只是近似，且图片单选、文字多选，二者不对称 |
| 拼图、截图、人物主导等呈现格式的组间差异 | 图文**正负相反或一致**：图片侧没有已启用的评价或状态字段，V5／V6方向只覆盖主导评价 |
| — | 创作者意图、平台算法的作用、受众是否更相信帖子 |

## 八、自拟例子

**例1。** 3个片段：海边散步（`rs_n_wat`=1）、海鲜（`rs_r_gas`=1）、酒店（`rs_r_arc`=1）。6张图：`VS-NAT`×3、`VS-FOD`×2、`VS-PEO`×1。

- 主映射：`T_NAT`=`T_BLT`=`T_FOD`=1；`n_img`=6，`n_map`=5；`s_NAT`=0.6，`s_FOD`=0.4，`s_BLT`=0。
- `A(p)`=1（文字写了酒店，没有建成环境图）；`B(p)`=0；人物主导占比=1/6。

**例2。** 1个片段：餐厅菜品与用餐环境（`rs_r_gas`=1）。4张图：餐厅空间`VS-FAC`×2、菜品`VS-FOD`×2。

- 主映射：`T_FOD`=1，`T_BLT`=0；`s_FOD`=0.5，`s_BLT`=0.5；`B(p)`=0.5，即餐厅空间图被算作“图有文无”。
- 宽松映射：`VS-FAC`同时计入D-FOD，`B(p)`=0。负责人关心的这类图文配合，只有在宽松映射下才会被识别为对应。
