## 一、目的与边界

本文回答一个问题：**V4（文字）与V7主要／次要主体（图片）能支持什么样的图文内容对应指标。**

- 采用10月21日确认的表述“内容对应／图文呼应”：同一帖子的文字提及与图片主体涉及同一**内容域**。
- 单位是帖子。文字取全部固定片段的出现性汇总，图片取本帖全部已判断图片；**不建立片段—单图对应**。
- 不合成单一“图文一致性得分”：内容对应、单向未对应、呈现格式分别报告。
- 测不到的内容见第七节，不由本文指标替代。
- 图片侧只记录主要主体和达到同样突出门槛的次要主体；文字侧记录资源提及，两者测量目标不同，不以盘点背景来追求对称。本文只分析“文字提及—图片主体”的类别层对应，不表示画面全部内容。

## 三、帖子层变量

记号：帖子*p*的固定片段集合*S(p)*，已判断图片集合*M(p)*，内容域*d*。图片*m*的主体集合`U(m)`包含主要主体及非NONE的次要主体；`V(m,k)=1`表示主体集合含类别*k*，否则为0。这是分析时派生的指示量，不新增人工0／1字段。

| 变量 | 定义 |
|---|---|
| `T_d(p)` | 文字提及：*S(p)*中任一片段的*d*域文字字段为1则为1；全部片段该域字段均为0则为0；否则（无1且存在UNRESOLVED）为NA，*p*不进入*d*域指标 |
| `K(d)` | 内容域*d*对应的主体取值集合；主映射D-BLT={VS-BLD, VS-FAC}，其他域各对应一个主体值（见2.1）；PEO、OTH不属任何域 |
| `n_img(p)` | 本帖已判断图片数：两字段满足本版约束，主要为12个正式取值之一，次要为允许的具名值或NONE；排除整组UNRESOLVED、旧记录NA、未完成或不符合约束的记录，并分别报告数量 |
| `s_d(p)` | 该域主体占比＝主要主体或次要主体属于K(d)的图片数÷n_img；同一图两字段均在K(d)中也只计一张；n_img=0时为NA |
| `J_d(p)` | 图片以该域为主体：s_d>0时为1，s_d=0时为0，s_d为NA时为NA |

分母为本帖全部已判断图片。主要为VS-PEO且次要为NONE、或主要为VS-OTH的图，对九个域均不贡献主体；主要为PEO但次要为资源类别时仍对对应域贡献一张。只有人物／其他主体的图不等于未决，也不从分母排除。

## 四、指标

### 4.1 主指标：对应差（每个内容域分别计算）

```text
Δ_d = E[ s_d | T_d = 1 ] − E[ s_d | T_d = 0 ]
```

含义：文字提及*d*的帖子，比不提及*d*的帖子，以*d*域为主体的图片占比高多少个百分点。

- **为什么用条件差而不用重叠率。** 若某域在文字和图片主体中都很常见，“任一重叠”可能偏高；这是一种指标风险，不是已观察到的样本结论。Δ用不提及该域的帖子作为基准：图片与文字无关时Δ约为0，正值才表示图片随文字内容而变。
- **为什么用占比而不用“是否出现”。** 图片越多，某域至少有一张主体图的概率越高；占比对图片数量不那么敏感。二元版本作为敏感性分析（4.3）。
- **为什么按域条件化。** 比较对象限于提及或不提及同一域的帖子，因此某组多写美食，不会机械地抬高该组的D-FOD对应差；题材差异另由RQ2的V4轮廓报告。

### 4.2 描述指标

| 指标 | 定义 | 用途 |
|---|---|---|
| 文到图呈现率 `R_d` | P(`J_d`=1 ∣ `T_d`=1) | 文字提及*d*的帖子中，至少一张图片以*d*为主体的比例 |
| 图到文提及率 `Q_d` | P(`T_d`=1 ∣ `J_d`=1) | 至少一张图片以*d*为主体的帖子中，文字也提及*d*的比例 |
| 文有图无 `A(p)` | Σ_d T_d(p)·(1 − J_d(p)) | 文字提及、但没有图片以该域为主要或次要主体的域数；不是图片遗漏的内容数 |
| 图有文无 `B(p)` | 本帖所有可映射的“图片—主体类别”对中，该主体所属内容域均未被文字提及（对所有含k的域，T_d=0）的对数÷全部可映射对数 | 只统计十个资源主体值，不含PEO、OTH、NONE；一图可有两个不同主体对，同一主体映射多个域也只计一对；不是背景内容或额外信息的数量 |
| 呈现格式 | 主要主体为VS-OTH、VS-PEO的图片分别占n_img的比例 | 其他／无明确主体、人物主导的组间差异；不能据OTH占比直接认定为拼图或截图占比 |

`R_d`、`Q_d`、`A`、`B`都受该域本身出现率的影响，不单独解释为对应强弱。`A`与`B`须对照置换基准（4.4）。

**主体口径的解释限制。** A只看主体：相对于盘点全部画面内容，其“文有图无”计数天然更易偏高（在相同类别判据下不会因只看主体而降低），但它衡量的是“图片未以该域为主体”，不能解释为遗漏或未出现。B同样只描述未被文字提及的资源主体，不代表画面全部内容或额外信息；作为比例，其变化方向不能预先断言。没有可映射主体对时B=NA，不补0。A、B只在计算涉及的文字域均已判断时计算，缺失与未决不得当成未提及。

### 4.3 敏感性分析（与主指标一并预先确定）

| 编号 | 改动 | 检查什么 |
|---|---|---|
| S1 | 映射M1代替主映射 | 餐饮空间是否改变D-FOD的结论 |
| S2 | 映射M2代替主映射 | D-BLT合并是否掩盖历史类与设施类的差异 |
| S3 | 二元版：`Δ^J_d` = P(`J_d`=1 ∣ `T_d`=1) − P(`J_d`=1 ∣ `T_d`=0) | 结论是否依赖“占比”这一选择 |
| S4 | 按图片数分层（1张、2—4张、5—9张、10张及以上）分别计算Δ | 图片数量的组间差异是否驱动结果 |
| S5' | 保持已判断图片集合及n_img不变，仅用主要主体重算s_d、Δ、A、B；B的分母相应改为主要资源主体对数 | 检验次要主体是否改变结论；主分析仍使用主要＋次要 |
| S6 | 只用首图（显示顺序第一张）代替全部图片 | 封面与正文配图是否表现不同；需先核实平台`img_id`即显示顺序 |
| S7 | 排除主要主体为`VS-OTH`的图片占比 ≥ 0.5 的帖子 | 其他／无明确主体图占比高的帖子是否主导组间差异 |

### 4.4 置换基准（用于`A`、`B`等描述指标）

在同一平台、同一图片数分层内，固定文字编码不变，把各帖的整组图片编码随机互换，重新计算指标；重复1,000次，报告“观测值 − 置换均值”及置换分布的2.5%—97.5%区间。差值接近0表示该描述量与图文无关的随机配对没有区别。

## 五、组间比较（H6）

**作者等权。** 旧切片中多数作者只有一帖，对应差不能在作者内部计算，故按条件格作者等权：

```text
E_g[ s_d | T_d = c ] = 组g内、至少有一篇满足 T_d = c 的作者，各自在这些帖子上的 s_d 均值，再对作者取平均
Δ_d,g = E_g[ s_d | T_d = 1 ] − E_g[ s_d | T_d = 0 ]
```

一名作者可以同时进入c=1和c=0两个格。

**比较与不确定性。** 报告各组的Δ_d,g及组间差Δ_d,g1 − Δ_d,g2；在组内按作者重抽样（2,000次）求区间，组别差异用作者层面的组标签置换检验。每个平台先分别报告，合并时按平台分层。九个内容域同时检验，须在看结果前确定多重比较的处理（例如控制错误发现率），不事后选择显著的域。

**格子支持。** Δ_d,g需要c=1与c=0两个格都有足够作者。每格最低作者数应与R6一并在看结果前确定，本文不替其决定；未达标时只报告描述量。稀有域（如D-CLI、D-GDS、D-LIF）较可能达不到，预期这些域只报告描述量。

## 七、能说与不能说

| 指标支持的陈述 | 指标不支持的陈述 |
|---|---|
| 某域被文字提及与被图片选作主体的类别层对应 | 图文指向同一对象；例如文字写栈桥、图片拍八大关，仍可能同属建成环境 |
| 各组“文字提及但图片未以该域为主体”与“图片以某域为主体但文字未提及”的差异及置换基准 | 图片遗漏了什么，或图片提供了多少额外信息；背景内容不在本字段测量范围内 |
| 人物主导、其他／无明确主体等呈现格式比例 | 图文正负相反或一致；图片侧未启用的状态字段不能补足这一判断 |
| — | 未编码为主要／次要主体的内容在图片里不存在 |
| — | 十个资源主体以外的内容与文字资源对应；PEO、OTH不属于内容域 |
| — | 创作者意图、平台算法作用、受众是否更相信帖子 |

## 八、自拟例子

以下均为虚构教学数据，不是原始样本裁决；所给文字字段值为演算输入，不据简短画面或片段描述重新裁定文本规则。仅复算示例，不表示已有实证结果。

**例1。** 假定3个片段分别提及海、海鲜、酒店，文字字段rs_n_wat、rs_r_gas、rs_r_arc各有1，其余域均为0。6张图按主体口径填写：

| 图 | 虚构画面 | visual_subject | visual_subject_2 |
|---|---|---|---|
| I1 | 海面与礁石同样突出，海面居构图中心 | VS-WAT | VS-GEO |
| I2 | 海面单主体 | VS-WAT | NONE |
| I3 | 海面与建筑同样突出，海面居构图中心 | VS-WAT | VS-BLD |
| I4 | 菜品特写 | VS-FOD | NONE |
| I5 | 饮品特写 | VS-FOD | NONE |
| I6 | 人物近景，其他内容只作背景 | VS-PEO | NONE |

- n_img=6；T_WAT=T_FOD=T_BLT=1，其余域为0。
- s_WAT=3/6=1/2，s_FOD=2/6=1/3，s_BLT=1/6，s_GEO=1/6；其他域主体占比为0。
- A=0：三个文字提及域均有对应主体图。B=1/7：共7个可映射图片—主体对（I1两对、I2一对、I3两对、I4和I5各一对），仅GEO一对所属域未被文字提及；人物主体不进入B分母。主要人物占比=1/6，主要OTH占比=0。
- S5'仅取主要主体：s_WAT=3/6、s_FOD=2/6、s_BLT=s_GEO=0；A=1（建成环境未作为主要主体），B=0/5=0。
- T_BLT来自酒店，I3的建筑可以是普通建筑；域层对应不表示拍的是同一家酒店。这里只能演算单帖量，不能从单帖计算需要T=1和T=0两个条件格的Δ。

**例2。** 假定文字侧仅rs_r_gas=1，其余域为0。4张图：餐厅空间为主要主体（VS-FAC）两张、菜品为主要主体（VS-FOD）两张；次要均NONE。

- 主映射：T_FOD=1，T_BLT=0；s_FOD=2/4=1/2，s_BLT=2/4=1/2；A=0，B=2/4=1/2（FAC两对所属D-BLT未被文字提及）。
- M1把VS-FAC同时计入D-FOD：s_FOD=4/4=1，s_BLT=2/4=1/2；A=0，B=0/4=0，因为FAC所属域含被文字提及的D-FOD，不再满足“所属域均未提及”。类别对分母仍为4，不能因FAC对应两个域而重复计数。
- S5'在本例不改变以上两种映射各自的结果，因为所有次要主体均NONE。主映射已识别菜品图的饮食对应，M1额外把餐厅空间主体计入饮食；这只是映射差异，不证明M1更有效。
