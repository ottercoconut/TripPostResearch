## 一、争议结论

“一个样本最多只能编码4—5个标签”不是结构化内容分析的通行硬性上限。编码数量应由研究问题、分析单位和材料复杂度决定；但代码越多、标签越稀有、边界越相似，编码员的认知负担和漏标概率通常越高，一致性也更难维持（O'Connor & Joffe, 2020）。因此，本研究既不把所有维度强制改成单标签，也不把所有逻辑组合另建为新类别。

本轮采用以下原则：

1. **逐字段人工判断**：编码表中进入人工记录表的父类、子类、排除项、适用性与量表字段均由编码员独立填写；逻辑上可核对不等于允许程序派生。
2. **真实共现**：信息、评价、建议等可以在同一片段出现的功能分别记录为0/1。
3. **真正互斥**：视觉主体、人数档位、景别等同一测量轴内部保留单选。
4. **全字段人工判断**：父类、子类、排除项、适用性和强度均由编码员填写；“其他/无”不由程序补写。
5. **层级不等于派生**：旧编号V5并入`CS-INT`子项层，V6独立于V5；父子及跨维度关系只用于冲突审计和候选层级损失。
6. **不把组合当新类别**：独立Sigmoid不要求训练集覆盖全部`2^K`种组合；若研究特定组合或高阶依赖，仍须检查该组合的实际样本数（Zhang & Zhou, 2014; Read et al., 2011）。

## 三、文本轨边界复核

### 3.1 V3：CS-INF、CS-EDU与CS-EMO

| 标签 | 只判断什么 | 不判断什么 | 例子 |
|------|------------|------------|------|
| CS-INF | 是否提供可用于旅行决策的价格、路线、时间、地点、清单或步骤 | 不把所有事实陈述都视为实用信息 | “地铁3号线到青岛站，人均200元” |
| CS-EDU | 是否解释历史、文化、地理、非遗或地方知识 | 不因出现地名就自动标知识 | “栈桥始建于1892年” |
| CS-EMO | 是否通过感官描写或氛围语言营造体验 | 不把所有好坏评价都视为渲染 | “海风带着咸味，落日把海面染成金色” |

同一片段可同时调用实用信息、知识阐释和情感渲染，不再选择“主要策略”。商业推广不属于V3；V1只在帖子级记录是否观察到明确商业披露。

### 3.2 V3与V5的交叉边界

- `CS-INF`是**内容策略**，只覆盖面向旅行决策的实用信息；`AT-INF`是**语言功能**，覆盖任何可核验命题。因此“栈桥始建于1892年”可为`CS-EDU=1, AT-INF=1`。
- `CS-EMO`是感官或氛围渲染；`AT-EVL`是明确价值判断。“海风吹过来很舒服”可以二者共现；“海风带着咸味”可只有CS-EMO；“门票很贵”可只有AT-EVL。
- `CS-INT`及`is_que/is_dir/is_soc/is_oth/is_non`全部人工判断；`IS-DIR`只记录互动行动号召，普通旅行建议进入`AT-SUG`。

这些字段相关并不等于定义重复。试标时应查看经验相关：若两个标签几乎总是同时出现，再检查是否仍具有区分效度。

### 3.3 V4：十一个资源亚类与四个事件子类

V4保留多标签，因为一个片段可以真实调用多类资源。降低负担的方式不是强制单选，而是：

1. 标注界面按父类和子类分色导航，但不以界面分组改变观察单位或字段责任。
2. V4证据按现行编码表记录：标`?`时必须定位，其余阳性项可选；词表只作提醒，不自动定类。
3. `RS-R-HIS`按文本中的历史、遗产或年代属性判断；`RS-R-ARC`按建筑外观造型、空间设计或住宿、交通、服务等当代使用功能判断。历史建筑只呈现外观且相关语境未调用历史／遗产意义时可归ARC，不凭景点名或外部知识补HIS。同段两类内容均有直接证据时可以共现，只有历史意义不自动增加ARC。
4. `rs_n`与`rs_r`仍由编码员判断；与Layer 2的OR关系只作复核。
5. `RS-R-REC`记录不依赖特定场次、赛期、节期、展期或届次即可反复获得的休闲、运动、观光与参与体验；`RS-R-EVT`记录依赖上述时限事件的体验。是否收费、是否由机构组织均不是分界标准。
6. `EVT-SPT`、`EVT-PER`、`EVT-FES`和`EVT-OTH`只在事件父类下细分；音乐节等复合事件可按直接证据并标。事件不会自动触发`RS-R-FOL`、`RS-R-GAS`或`RS-R-ARC`。
7. `rs_r_act = rs_r_rec OR rs_r_evt`只在分析阶段汇总，不作为人工金标或模型输出；旧`rs_r_act`记录不能自动迁移，须回到原文重编码。

### 3.4 V5、V6与旧编号V5

- AT-INF、AT-EVL、AT-SUG分别回答“有无事实命题”“有无价值判断”“有无行动建议”，不设优先级。
- 只标文本明确表达，不把“看到了城市全貌”推断成“壮观”，也不把“人很多”自动推断成“热闹”或“拥挤”。
- 情感方向只在片段含评价或建议且方向可判定时人工标注；正负强度分别填写0/1/2。任何净值只在分析阶段生成。
- V6只在评价或建议明确指向目的地属性时适用。V6不携带正负方向；评价对象或方向切换须强制切分，使V5情感与V6属性在同一`seg_id`内配对。
- 旧编号V5已并入V3-CS-INT子项层。`is_que/is_dir/is_soc/is_oth`可以共现；`is_non`和正向互动子项分别人工判断，逻辑冲突只进入复核。

## 四、视觉轨边界复核

### 4.1 V7视觉主体

V7仍保留五类单选，因为它测量“画面中最主要的可见对象”。多主体时先看视觉突出度，再看面积；面积接近、拼图或遮挡图片且编码员确实拿不准时标`?`，锁定后进入复核。`VS-PEO`不能以“画面有人”作为充分条件，人物须为主体。

### 4.2 V8视觉呈现方式

原五类不是同一测量轴。例如栈桥可以同时是标志性场景、全景和航拍。拆分后：

- `scene_context`：SC-ICO标志性场景、SC-STR日常场景、SC-OTH其他/不适用；
- `shot_scale`：SS-CLO特写、SS-MID中景、SS-PAN全景；
- `viewpoint`：VP-GRD平视/常规、VP-HIG高位俯视、VP-AER航拍。

标志性场景仍依赖目的地知识。正式编码前应建立青岛地标白名单及图例，未在白名单但可能具有代表性的对象标`?`并说明，不能由编码员随意扩展。

### 4.3 V9人物呈现

人数是可见计数，互动是关系判断，两者不能互斥。`people_count`按0人、1人、2人及以上单选；`human_scene_interaction`只有在人物与目的地元素发生明确接触、操作或面向性交互时为1。创作者身份和人物关系不从单图推断；已删除的`creator_appears`不在当前编码体系中恢复。

### 4.4 V10消费符号

品牌存在性与品牌类型存在父子关系，但可识别的其他品牌可能只满足`CS-BRA=1`。因此四个字段全部由编码员判断；父子关系仅用于一致性审计，不得自动补写。

### 4.5 V11可见对象状态

V11的主要主观风险不是“正面还是负面”，而是状态轴是否被触发、可见范围是否足够以及审美线索是否被误当作对象状态。四组正负字段彼此独立：没有相关对象或可见范围不足时记`NA`；状态轴适用但某标签不成立时记`0`；混合证据允许同轴正负同时为1。危险源和防护措施也独立判断，未见防护不能反推不安全，见到防护也不能反推无风险。

## 五、仍未由结构改造解决的风险

| 风险 | 影响 | 控制方案 |
|------|------|----------|
| 语义片段切分 | 不同单位会使标签信度不可直接比较 | 编码前固定`seg_id`；试标阶段单独裁决边界 |
| 隐含评价/建议 | 编码员可能把语用推断当文本证据 | 采用“只标明确表达”规则并积累反例 |
| 低频标签 | alpha/kappa和模型召回率不稳定 | 分层/定向抽样；报告阳性数与置信区间 |
| V8标志性场景 | 依赖目的地知识 | 地标白名单、图例和疑问标记复核 |
| V1明确商业披露 | 披露可能出现在标签、正文或平台披露区域 | 仅按可观察的明确声明作0/1判断；不从正面程度或写作风格推断商业关系 |
| 创作者跨平台分层 | 绝对粉丝阈值的平台可比性有限 | 绝对阈值作主分析，平台内分位数作敏感性分析 |
| V6属性—情感错配 | 同一片段包含多个对象或方向会产生错误配对 | 评价对象或情感方向切换时强制切分；只在同一`seg_id`内关联 |
| V11可见范围 | 远景、裁切或滤镜可能造成伪阳性 | 适用性先行、直接可见证据、NA/0分开并复核带疑问标记的样本 |

结构拆分只能提高可操作性，不能预先证明主观性已经下降。最终证据来自试标后的逐标签分歧模式和信度结果。

## 六、分层人工证据方案

### 6.1 试标与冻结

1. 约20—30篇用于共同校准，只讨论规则和边界，不计算正式信度。
2. 共同校准前使用统一`1/0/UNK/NA`语义；无法唯一裁决时暂记`UNRESOLVED`并登记问题，校准后决定字段专门规则。
3. 每个主观字段先填写标签值；只有确实拿不准时才标`?`并记录原因、替代值和一句说明，锁定后进入重点复核。
4. 实质性阳性判断统一使用`evidence_spans_json`定位不可变`raw_text`；offset从0开始、左闭右开，并保存`quote`校验。
5. 另取约70—80篇新样本，两位编码员在相同固定片段上独立盲标V3、V4、V5和V6；旧编号V5子项随V3-CS-INT一起评估。
6. 完成后按标签检查信度、类别支持、分歧原因、证据位置、条件缺失和共现频数；`alpha >= .80`且无系统性边界分歧时不追加字段专门规则。
7. 若编码表发生实质修订，升内部版本并用新的未讨论样本重新确认；不能在已协商样本上证明信度提高。

### 6.2 评估金标、训练标注与裁决

锁定测试集由两位编码员全部独立编码并形成共识金标；训练池由主编码员标注，第二人复核预注册随机比例及全部稀有、带疑问标记和冲突样本。“500篇”只是初始预算锚点，不等于全部双标。每个原子标签主报告一种适合其尺度的Krippendorff's alpha，同时报告原始一致率和各值支持数；Cohen's kappa、阳/阴性一致率和集合距离仅在解释稀有标签或特殊分歧时补充，不再作为每个字段的固定报告负担。项目质量门槛为`alpha >= .80`；`.667-.80`只作暂定使用并须复查，低于`.667`的标签不进入模型训练。疑问标记不进入alpha计算。

信度计算使用裁决前数据。团队在信度报告完成后依据证据位置和已冻结的编码表裁决分歧，形成模型使用的金标；编码簿只是执行说明。

### 6.3 训练与测试

按`author_id`和重复簇分组切分，防止相同作者或近重复内容跨训练、开发和测试。具体数量由逐标签阳性数、区间宽度与人工预算决定，不预设350/150。测试集不得参与主动学习、阈值选择或调参；若核心稀有标签的测试阳性数不足，应追加独立定向评估样本，而不是从训练结果中挑选案例。

## 七、对神经网络结构的直接影响

```text
共享文本编码器
  ├── V3：5个父类 + 22个子项逐字段输出
  ├── V4：2个资源父类 + 11个Layer 2亚类 + 4个事件子类逐字段输出
  ├── V5：4个语言功能字段逐字段输出
  ├── V5评价亚类：条件分类（基数由T0裁决）
  ├── V5方向：POS/NEG/MIX/NEU条件分类
  ├── V5强度：正向/负向两个0/1/2条件输出
  └── V6：适用性 + 4父类 + 14子类 + 其他项逐字段输出

规则层
  ├── 父子关系只作层级一致性审计或候选层级损失
  ├── 不以规则覆盖任何模型概率或人工金标
  ├── 结构性NA不参加对应字段损失
  └── 净情感只在分析阶段由双向强度计算
```

模型性能须逐标签报告Precision、Recall、F1和PR-AUC，并给出macro/micro汇总、支持数、概率校准、分平台/创作者层级表现及主要帖子级/作者级估计的人工金标—模型差值。Exact Match可以补充，但不应作为多标签任务的唯一指标。SRM/SAM及其他候选指标在对应`DEFERRED`状态解除后追加下游偏差验证。本轮编码方法改进不简化这一研究设计。

## 八、历史结论与当前待试标事项

### v3.4时期结论（已由后续编码表取代）

1. V1、V3、V5不再设置主标签或优先级。
2. 当时曾主张`CS-INT`与“无/其他”字段由程序派生；该结论已被v3.7.0的全字段人工责任取代。
3. V2当时保留九个可共现资源亚类，并分为4项/5项两个标注模块；该结构已由v3.10.0的十个Layer 2亚类与四个事件子类取代。
4. V12拆为场景语境、景别、视角；V14拆为人数、互动。
5. 当时曾保留概率净方向；现行标准改为人工双向强度，净方向仅在分析阶段计算。

### 当前待试标后决定

1. `at_eval_subtype`的单选/多选责任、多评价共现裁决与人工信度门。
2. V2的`REC/EVT`时限边界、复合事件子类共现，以及事件与民俗、饮食、设施资源的并标边界。
3. V12地标和“其他/不适用”边界，以及视觉研究人口。
4. V11各状态轴的对象触发、最低可见范围、NA/0/UNK边界与正负共现裁决。
5. 稀有标签是否需要定向扩样，以及哪些共现关系进入推断统计。
6. 是否需要标签依赖模型；独立逐字段基线和样本证据不足前不增加复杂结构。
