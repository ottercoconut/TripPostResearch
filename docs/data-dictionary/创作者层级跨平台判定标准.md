## 一、问题背景

现有V0.1采用绝对粉丝量阈值（H-KOL>100万、W-KOL 10-100万、T-KOL 1-10万、KOC<1万）作为跨平台统一标准。但不同平台的粉丝基数差异巨大：

| 平台 | 100万粉丝的实际影响力 | 按绝对阈值分类 | 实际层级 |
|------|---------------------|---------------|----------|
| B站 | 顶级UP主 | H-KOL | ✅ H-KOL |
| 抖音 | 腰部偏上 | H-KOL | ⚠️ W-KOL |
| 小红书 | 头部创作者 | H-KOL | ✅ H-KOL |
| 微博 | 中下游 | H-KOL | ❌ T-KOL甚至KOC |
| 携程 | 粉丝概念弱 | 不适用 | — |
| 知乎 | 高价值腰部 | H-KOL | ⚠️ W-KOL |
| 豆瓣 | 不显示精确粉丝数 | 不适用 | — |

**结论**：绝对粉丝量阈值在跨平台比较时缺乏效度，需要建立多指标综合判定体系。

---

## 二、判定框架：四维度综合评估

```
创作者层级 = f(平台内粉丝分位数, 平台官方等级, 互动率, 账号活跃度)
```

| 维度 | 指标 | 权重 | 数据来源 | 说明 |
|------|------|------|----------|------|
| D1 影响力规模 | 平台内粉丝量分位数 | 40% | 采集时记录粉丝量，事后计算分位数 | 在该平台内的相对位置 |
| D2 平台认证 | 平台官方创作者等级/认证 | 30% | 采集时从页面提取 | 平台官方对创作者的综合评定 |
| D3 内容效能 | 互动率 | 20% | 需计算：(点赞+评论+收藏)/粉丝量 | 内容实际触达和转化能力 |
| D4 持续性 | 账号月龄 + 发帖频率 | 10% | 需计算：首帖日期、总帖数 | 创作者的持续产出能力 |

---

## 三、各维度操作化定义

### D1 平台内粉丝量分位数（主要依据，权重40%）

**计算方法**：
```
平台内分位数 = rank(该创作者粉丝量, 该平台所有样本) / 该平台样本量 × 100%
```

**分位数→层级映射**：

| 分位数 | 对应层级 | 含义 |
|--------|----------|------|
| ≥ 95% | H-KOL | 平台内前5%——头部创作者 |
| 80% - 95% | W-KOL | 平台内前5%-20%——腰部创作者 |
| 50% - 80% | T-KOL | 平台内前20%-50%——长尾创作者 |
| < 50% | KOC | 平台内后50%——素人/消费者型创作者 |

**注意**：
- 分位数需在**同平台样本内**计算，不跨平台比较
- 若某平台样本量<30，分位数不稳定，需结合其他维度判定
- 携程、豆瓣等粉丝概念弱的平台，D1权重降至20%，D2权重提升至50%

### D2 平台官方创作者等级/认证（重要参考，权重30%）

| 平台 | 官方等级体系 | 提取字段 | 等级→层级映射 |
|------|-------------|----------|--------------|
| **抖音** | 创作者等级（L1-L6）+ 认证标识 | creator_level, is_verified | L5-L6→H-KOL, L3-L4→W-KOL, L1-L2→T-KOL |
| **小红书** | 蒲公英等级（普通/银冠/金冠/皇冠）+ 认证标识 | creator_level, is_verified | 皇冠→H-KOL, 金冠→W-KOL, 银冠→T-KOL, 普通→KOC |
| **B站** | UP主等级（Lv1-Lv6）+ 认证标识 | creator_level, is_verified | Lv5-Lv6→H-KOL, Lv3-Lv4→W-KOL, Lv1-Lv2→T-KOL |
| **微博** | 认证体系（金V/橙V/蓝V） | verification_type | 金V→H-KOL, 橙V→W-KOL, 蓝V→T-KOL, 无认证→KOC |
| **携程** | 达人等级（普通/铜牌/银牌/金牌/钻石） | creator_level | 钻石→H-KOL, 金牌→W-KOL, 银牌→T-KOL, 铜牌/普通→KOC |
| **知乎** | 盐值 + 创作者等级 + 优秀回答者标签 | salt_value, creator_level, is_excellent | 优秀回答者+高盐值→W-KOL, 创作者等级高→T-KOL |
| **豆瓣** | 无官方等级体系 | — | 该维度不适用，仅用D1+D3判定 |

**采集时需额外记录的字段**：

| 字段 | 类型 | 说明 | 适用平台 |
|------|------|------|----------|
| platform_creator_level | str | 平台官方创作者等级（原始值） | 抖音/小红书/B站/携程/知乎 |
| platform_verification | str | 平台认证标识（原始值） | 全部七平台 |
| platform_badge | str | 平台特殊标签（如"优秀回答者""超话主持人"） | 知乎/微博 |

### D3 互动率（辅助参考，权重20%）

**计算方法**：
```
互动率 = (点赞数 + 评论数 + 收藏数 + 转发数) / 粉丝量 × 100%
```

**互动率→层级映射**（跨平台参考值）：

| 互动率 | 倾向判定 | 说明 |
|--------|----------|------|
| > 5% | 倾向KOC或垂直领域T-KOL | 粉丝少但粘性高，典型素人口碑 |
| 1% - 5% | 倾向W-KOL / T-KOL | 典型腰部创作者 |
| < 1% | 倾向H-KOL或粉丝质量存疑 | 粉丝基数大导致互动率自然摊薄，或存在僵尸粉 |

**注意**：
- 互动率受内容类型影响大（攻略类天然低于情感类），需在同平台内比较
- 单条帖子的互动率波动大，建议用该创作者**近10条帖子的平均互动率**
- 若粉丝量数据缺失，D3权重降至0，由D1+D2+D4补充

### D4 账号活跃度（辅助参考，权重10%）

**计算方法**：
```
账号月龄 = (采集日期 - 首帖日期) / 30
月均发帖量 = 总帖数 / 账号月龄
```

**活跃度→层级映射**：

| 指标 | KOC特征 | KOL特征 |
|------|---------|---------|
| 账号月龄 | < 12个月 | > 24个月 |
| 月均发帖量 | < 2条/月 | > 4条/月 |
| 内容垂直度 | 旅游帖占比 < 30% | 旅游帖占比 > 60% |

## 四、综合判定流程

```
步骤1：记录原始数据
  ├── 粉丝量
  ├── 平台官方等级/认证
  ├── 近10条帖子的点赞/评论/收藏/转发数
  └── 首帖日期、总帖数

步骤2：计算各维度得分
  ├── D1：平台内粉丝分位数（需同平台样本完成后计算）
  ├── D2：平台官方等级→层级映射
  ├── D3：互动率→层级映射
  └── D4：账号月龄+发帖频率→层级映射

步骤3：综合判定
  ├── 若D1和D2一致 → 直接判定
  ├── 若D1和D2不一致 → 参考D3和D4，取多数维度一致的层级
  ├── 若四个维度中有3个以上指向同一层级 → 直接判定
  └── 若无法判定 → 标记为"待定"，人工复核

步骤4：校验
  ├── 跨平台校验：同层级创作者在不同平台的互动率应处于相近区间
  └── 异常值处理：互动率极高但粉丝量极低→可能是"虚假繁荣"，降一级
```

**判定示例**：

| 创作者 | 平台 | 粉丝量 | 平台等级 | 互动率 | 月龄 | 综合判定 |
|--------|------|--------|----------|--------|------|----------|
| A | 抖音 | 150万 | L5 | 0.8% | 36月 | H-KOL（D1前5%+D2=L5，一致） |
| B | 抖音 | 150万 | L3 | 3.2% | 12月 | W-KOL（D1前5%但D2=L3，D3=中等，降为W-KOL） |
| C | 微博 | 150万 | 金V | 0.3% | 48月 | H-KOL（D2=金V+D4=高活跃，一致） |
| D | 微博 | 150万 | 蓝V | 0.5% | 6月 | W-KOL（D2=蓝V+D4=低活跃，降级） |
| E | 小红书 | 8000 | 银冠 | 8.5% | 18月 | T-KOL（D1前50%+D2=银冠+D3=高互动） |
| F | 豆瓣 | 无数据 | 无 | 12% | 24月 | KOC（D3=极高互动率+D4=长期活跃，但D2=无等级，判定为KOC） |

## 五、编码表记录格式（更新）

### 帖子级元数据（新增字段）

| 字段 | 类型 | 说明 |
|------|------|------|
| author_tier | str | 综合判定结果：H-KOL / W-KOL / T-KOL / KOC |
| author_tier_confidence | str | 判定置信度：HIGH / MEDIUM / LOW |
| follower_count | int | 粉丝量（原始值） |
| follower_percentile | float | 平台内粉丝分位数（0-1，事后计算） |
| platform_creator_level | str | 平台官方等级（原始值） |
| platform_verification | str | 平台认证标识（原始值） |
| engagement_rate | float | 互动率（近10条平均，事后计算） |
| account_age_months | int | 账号月龄（事后计算） |
| monthly_post_freq | float | 月均发帖量（事后计算） |

### 判定置信度标准

| 置信度 | 条件 |
|--------|------|
| HIGH | D1和D2一致，或4个维度中3个以上指向同一层级 |
| MEDIUM | D1和D2不一致，但D3和D4支持其中一方 |
| LOW | 各维度指向不一致，或D1/D2数据缺失 |

## 六、注意事项

1. **分位数需在数据采集完成后计算**：D1平台内粉丝分位数需要该平台所有样本的粉丝量数据，无法在采集时实时判定。建议流程：先采集→再计算分位数→最后判定层级。

2. **携程和豆瓣的特殊处理**：这两个平台粉丝概念弱，D1权重降至20%，D2权重提升至50%。携程有达人等级体系可直接使用；豆瓣无官方等级，主要依赖D3互动率和D4活跃度判定。

3. **单条帖子数据的局限**：D3互动率需要该创作者的多条帖子数据。若只采集到单条帖子，互动率置信度较低，D3权重降至10%。

4. **MCN机构的影响**：若V0.2记录auth_type=MCN，该创作者的职业化程度较高，可作为D2的补充参考——MCN旗下创作者通常至少为T-KOL级别。

5. **动态更新**：创作者层级可能随时间变化（如从KOC成长为T-KOL）。建议在数据采集时记录采集日期，以便后续分析时控制时间窗口。
