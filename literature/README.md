# 文献管理

本目录保存文献元数据、检索过程、阅读笔记和本地全文：

- `notes/`：个人工作用阅读笔记与证据摘录，默认不提交新的文件；
- `papers/`：本地论文 PDF，可能受版权限制，默认不提交 Git；
- DOI、BibTeX/RIS/CSL JSON 与检索记录暂时以 `references.*`、`search_*.md` 等明确文件名放在本目录，文件增多后再分类；
- [`理论储备阅读包.md`](理论储备阅读包.md)：按理论簇组织的入门阅读顺序、每篇的读法、三栏笔记模板与阅读入口；是阅读指南，不是系统综述或理论承诺。

> **当前库位置提示（2026-08-23）**：`literature/papers/`尚未承载既有全文；当前实际原文库位于仓库根目录的`../papers/`。在完成单独的迁移治理决定前，不得假定前者完整，也不得擅自批量移动或重命名后者。理论收缩的已核验来源见[`理论收缩证据台账_2026-08-23.md`](理论收缩证据台账_2026-08-23.md)。

论文引用以 DOI 和正式题录为准，不能仅依赖本地 PDF 文件名。
